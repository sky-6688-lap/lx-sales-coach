# 17 门禁实战手册：信息不全时怎么问、怎么给

> 补 SKILL.md 第三节。处理「用户给了一半背景」「只贴了聊天记录」「不给原话」「反复说别问了」等边界情况。

## 一、门禁不是问卷，是防止写出废话

三件事 + 一句原话的作用是确定**力度**：卖什么决定用词，价格带决定沟通深度，关系进度决定这一句该往前推还是往回退，客户原话决定接住哪个词。**前三项任一缺失，不给成品消息**；第四项必须先问一句，用户明说「没有原话」即可按中性力度给，但不猜客户措辞、不写「他说过……」，并在依据段标注这一限制。缺项还硬写，出来的消息通常很完整、很礼貌，但用户改不完就发不出去。

**判断顺序**：先扫一遍用户这条消息里已经给了什么，只补缺的，不重复问已经给过的。用户说「2980 的陪跑，客户说再考虑一下」——价格与关系进度已隐含、原话已给，只缺「上次聊到哪一步、报过价没有」，就只问这一项。

## 二、十二种常见输入与对应反问

| 用户输入的样子 | 已具备 | 只补这一项 | 反问口径 |
|---|---|---|---|
| 「客户说太贵了怎么回」 | 原话 | 卖什么 / 价格档 / 进度 | 三件事一起问，一轮问完 |
| 「报价三天没回」 | 进度 | 卖什么 / 价格档 / 有无原话 | 「卖的是什么、哪个价位？对方最后那句还记得吗」 |
| 「客户要考虑一下」 | 原话 | 三件事 | 「这单卖什么、什么价位、上次聊到哪儿」 |
| 「2980 的陪跑，第二次聊」 | 价格 / 进度 | 原话 | 「他最后那句怎么说的，贴给我最好」 |
| 贴了一整段聊天记录 | 原话 / 部分进度 | 卖什么 / 价格档 | 「记录里没看到产品与价格，这两项补一下」 |
| 「老客户想续费，怎么开口」 | 进度 | 卖什么 / 价格档 / 上次交付到哪 | 「这次续的是什么、原来什么价、上一轮做完拿到什么」 |
| 「朋友问价，我不好意思收」 | 关系 | 三件事 | 「先说卖什么、正常价多少、他问的是哪一句」 |
| 「帮我写个成交话术」 | 无 | 全部 | 三件事 + 原话，一轮问完 |
| 「能不能便宜点，客户问的」 | 原话 | 三件事 | 同第一行 |
| 「我想涨价，怎么说」 | 进度（已成交） | 卖什么 / 原价格 / 新价格 | 「原来多少、想调到多少、范围有没有变」 |
| 「帮我出 5 条朋友圈」 | 无 | 场景 / 给谁看 / 禁用表述 | 走 16 与 61 的三项确认，不套销售门禁 |
| 「怎么让客户别再白问」 | 场景 | 卖什么 / 价格档 / 他白问了什么 | 「他一般问哪类问题、你正常怎么收费」 |

**一轮问完**是硬要求。分三次追问背景，比一次问三项更让人烦。

## 三、四种边界情况

**1. 用户明确说「别问了，先给一句」**
落 S8 占位版：≤2 条短消息，产品、价格、原话全部用 `[占位]`，末尾一句「补上背景我再给你按这单改一版」。不追第三句，不在消息里塞进自己编的产品名。

**2. 用户只给部分，且明显不想再补**
给「半定制版」：只写对已给信息成立的那部分，把缺的部分做成占位符，并说明「这块因为不知道价格档，先按中性力度写」。不要假装信息齐了。

**3. 用户贴的聊天记录里含第三方信息**
只抽取与判断有关的事实（谁说了什么、有没有报价、有没有回），不复述姓名、公司、联系方式、金额明细。输出里不出现这些。

**4. 用户反复改口背景**
以最后一次确认的为准，不翻旧账、不说「你刚才不是讲…」。判断随新信息重判，见 18 的误判纠正。

## 四、占位版的三条细则

- 占位符只放在**必须替换**的位置，最多 3 个：`[产品]`、`[价格]`、`[他的原话]`。多到 5 个以上，等于没给成品。
- 占位版不能含具体行业、具体金额、具体时间段；这些一写就成了预设。
- 占位版同样过风格六条与 [15-message-checklist.md](15-message-checklist.md)：不道歉铺垫、不开放式盘问、不制造稀缺。

## 五、门禁与状态机的衔接

四项齐了也别急着写：先用它们判状态。原话是「太贵了」不等于 S3 价格异议——如果记录显示还没报过价，那可能是 S0 价值没落地，对方在用「贵」提前挡。反过来，原话是「好的我看看」而价格已报，通常落在 S5 缺动作，不是 S4 沉默。

**别把门禁当终点**。它是让状态判定有依据的前置动作；判定完还要按 [00-router.md](00-router.md) 的顺序走一遍。

## 六、常见错误

- 把三件事做成三条分开发送的消息。
- 用户给了价格还问「客单价多少」。
- 用「为了更准确地帮到你」开场，然后再问五项。
- 门禁没齐却给了五个备选版本，用数量掩盖不确定。
- 把「别问了」理解成「可以随便编」。

## 七、禁忌

最忌讳**用反问拖延**：用户对着一单着急，连着两轮都在被问背景，第三轮就不会再提供信息了。信息不全时给占位版 + 一句补背景的说明，往往比纯反问更有用。
