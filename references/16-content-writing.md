# 16 销售内容：取材地图与成文模板

> 状态 S9：朋友圈、短文案、海报主文案、批量出稿。出稿前先读这一篇，写完过 [15-message-checklist.md](15-message-checklist.md)。

## 一、先过红线闸门，再确认三件事，再动笔

**本篇不是所有「帮我写两句」的入口**。动笔之前先做 SKILL.md 运行时规则 14 的判定：

- 用户要「写两句证明我做过的客户都有效果」「编个案例」「写前后对比」「报成交率」「引用好评」：先看他有没有贴出可核对的真实素材。**没贴就直说「这里没有可公开、可核对的客户案例，不能代写」**，给不含数字的替代动作（可核对的交付清单 / 请他补自己的案例 / 更小的第一次）。不写「以下成果均来自真实客户案例，经授权后脱敏展示」「客户A实现了[结果]」「已有[数量]位客户」「均可回溯」；把编造装进 `[占位]`、或假设用户手上有案例，同样算编。
- 用户要「把课程链接 / 咨询入口 / 扫码 / 预约承接加进话术」：说明不夹带，给不含链接与承接语的等价版本；不索要链接，也不写成「想系统学可以看课程：[课程链接]」。

命中以上任一条就停，不进本篇的出稿流程，也不用先补门禁四项。红线是动笔前的判据，不是写完再核对的备注。停下来的输出仍要有第 3 段：正文一句边界 + 引用块里一条 ≤60 字、不含案例与链接的等价消息；**第一句从边界起头**：不写「我会按文案场景写两句」「我会按成交教练的方式给你两句效果证明」「先确认一下链接」这类角色宣告或先答应后否定，也不索要链接或案例素材后才给替代版本（SKILL.md 规则 14）。

用户说「帮我写 50 条」时，不要直接开工。先确认（一轮问完，别逐个问）：

1. **发在哪**：朋友圈 / 群 / 海报 / 短帖，决定长度与开头。
2. **给谁看**：用用户说过的具体处境，不要「所有想成长的人」。
3. **禁用表述**：行业合规词、不想提的价格、不能公开的案例。

没确认就按最保守口径：不写价格、不写案例、不写成效数字、不写承接语。用户明确说「别问了」时按这个口径给，并标注假设。

**不承诺爆款、不承诺带来咨询量**。这批内容的作用是让人认出「这说的是我」，不是流量保证。

## 二、取材地图：四类内容，四个真实来源

| 内容类型 | 从哪里取 | 不能取什么 |
|---|---|---|
| 说清卖什么 | 用户自己的三格句（见 [01-value-and-positioning.md](01-value-and-positioning.md)） | 夸自己的形容词、行业黑话 |
| 展示过程 | 用户真实做过的一件事：遇到什么、怎么判断、哪一步最容易卡 | 编造的项目、包装过的前后对比 |
| 回应顾虑 | 客户真实问过的问题（脱敏、去身份信息） | 未授权截图、把私下对话原样贴出 |
| 给可自用的东西 | 清单、检查表、一个今天能试的动作 | 空泛的「方法论」「底层逻辑」 |

**经授权的反馈**才能用（见 [11-after-sale.md](11-after-sale.md)）：匿名、去金额、不加工成夸大结论。没有可用素材就写「这里可以补你自己的案例」，不用模板示例冒充。

## 三、成文骨架（四类通用）

```
1 一个具体处境（用目标读者会认出的那句话开头）
2 一个判断（这件事通常卡在哪，为什么）
3 一个可自用的动作 / 三步清单（真给东西）
4 一个具体的口子（一句话能回，不是「欢迎咨询」）
```

长度：朋友圈 80–200 字为主；海报主文案 1 句主标题 + 1 句副标题；短帖可拆成 3 条连发。

**模板示例（非真实案例，仅演示结构，不代表任何真实客户）**

> 有人改了三版简历还是没回音，其实卡的不是措辞，是没想清楚这一版要投给谁。
> 先别改格式，拿一张纸写出三个你做过的项目里最想被问到的那一个，再看简历里它排在哪。
> 排不到前两行的，就先挪位置。
> 如果你也卡在「方向有了但写不出来」，可以把你那三行发我，我帮你看顺序。

最后一句是具体口子，不是「私信我」「欢迎来聊」这类承接模块；后者属于红线，不写。

## 四、批量出稿规则

- **先定条数与差异维度**：例如 5 条 = 2 条说清卖什么 + 1 条展示过程 + 1 条回应顾虑 + 1 条给动作。同骨架换词不算不同内容。
- **逐条标注取材来源**：写清每条基于用户提供的哪件事；没有来源的条目标为「需补真实素材」，不要悄悄编。
- **不重复同一句原话**：不同客户的话不能混用。
- **不一次给 50 条同质内容**：先给 5–8 条，用户确认语气与边界后再扩。
- **每条都过自检**：尤其是不承诺、不编数字、无外部链接与承接模块。

## 五、表述红线（内容场景最容易踩）

- 健康：不写治疗、治愈、根治；教育：不写包过、保证提分、保 offer；金融：不写收益、稳赚。
- 不写「学员都已…」「好评如潮」「转化率提升 X%」这类无法核对的表述。
- 不写限时、名额、涨价预告、倒计时。
- 不出现第三方人名、机构名、社群名，不夹带外部课程、专栏链接。
- 对外只出现「乐享」品牌；不附加购买或咨询承接模块。

## 六、常见错误

- 把内容写成服务介绍连发，读者只能划走。
- 用「你是不是也…」开头连着三条，模板感太重。
- 每条都收在同一句引导语。
- 把用户没提供过的案例、价格、时间点补进去「让内容更完整」。
- 出完一堆，没有说明哪几条需要补真实素材。

## 七、交付格式

批量出稿时，每条给：编号 / 适用发布场景 / 正文 / 取材来源 / 需要用户补的一处（若有）。末尾附一句「全部已过表述红线，未使用未经授权案例」，不要写成免责声明式长段。
