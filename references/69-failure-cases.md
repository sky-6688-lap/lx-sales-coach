# 69 二十个「这样发就废了」的反面案例

> 与 [47-followup-mistakes.md](47-followup-mistakes.md) 的分工：那篇只讲跟进，这篇覆盖全链路。每条给「废在哪 → 换成什么」，示例均为**模板示例（非真实案例）**。

## 一、门禁与开局（1–4）

**1 没问背景就给五套话术**
- 废在哪：用数量掩盖不确定，用户一套也发不出去。
- 换：一轮问完三件事 + 原话，或给一条占位版。

**2 用户给了价格还问「客单价多少」**
- 废在哪：显得没读消息。
- 换：只补真正缺的那一项。

**3 首次开口发整段介绍 + 案例 + 价格 + 流程图**
- 废在哪：对方只能回「好的我看看」。
- 换：三句结构，接住 → 三格句 → 一个二选一。

**4 「不好意思打扰了，冒昧问一句」**
- 废在哪：道歉式铺垫，风格规则禁止。
- 换：第一句直接说事。

## 二、需求与报价（5–9）

**5 「你有什么需求？」**
- 废在哪：太抽象，多数人答不上。
- 换：第 1 层的具体现状问题（28）。

**6 需求没确认就报价**
- 废在哪：价格脱离「解决什么事」，后面只能比价。
- 换：先走需求确认句（03）。

**7 只发一个数字**
- 废在哪：没范围、没交付、没下一步。
- 换：报价三件套（02）。

**8 报完价立刻补三条解释**
- 废在哪：替价格辩护，显得心虚。
- 换：报完停住，等对方反应。

**9 「价格要看具体需求哦」**
- 废在哪：听起来像设套。
- 换：「价格可以直接给你，先确认对得上：[他提过的事] 吗？」

## 三、异议与信任（10–14）

**10 「其实不贵，你想想…」**
- 废在哪：反驳对方，且没分类。
- 换：34 的分类问句。

**11 一还价就降价**
- 废在哪：等于承认上一版报高了。
- 换：平答 + 范围选项（37）。

**12 「肯定没问题 / 保证有效」**
- 废在哪：越红线，交付期必然反噬。
- 换：说清可控制的两块 + 需要配合的部分（39）。

**13 编两个客户案例压过去**
- 废在哪：不编造是硬红线。
- 换：明说没有可公开案例，给小第一步。

**14 「你到底在顾虑什么？」**
- 废在哪：要求对方解释，只会得到「没什么」。
- 换：一个具体的小确认（38）。

## 四、跟进与收口（15–18）

**15 「考虑得怎么样了」**
- 废在哪：没有新东西，也不好回答。
- 换：「[范围里一项] 是这次一定要的吗？」

**16 「是不是我哪里没说清楚」**
- 废在哪：要求解释、带自我怀疑。
- 换：补一条有用信息 + 「不用回我」。

**17 「这周不定就要调价了」**
- 废在哪：虚假稀缺，红线。
- 换：给一个带日期的具体动作（48）。

**18 第 3 次之后「最后再试一次」**
- 废在哪：止损线被突破，前面所有消息都变味。
- 换：直接停，等真实由头（44）。

## 五、成交后与内容（19–20）

**19 刚收钱就推转介绍 / 复购**
- 废在哪：交付还没开始，信任被消耗。
- 换：先给排期与材料清单（50），转介绍等结果出现（54）。

**20 内容里写「学员都已…」「转化率提升 X%」**
- 废在哪：无法核对，且可能越行业合规。
- 换：写具体到能自己试的一步（59、61）。

---

## 三条共同病因

| 病因 | 表现 | 修正 |
|---|---|---|
| 替对方做决定 | 降价、加赠、催定、替他判断「不值」 | 给范围与可核对事实，决定权交回 |
| 要求对方解释 | 追问顾虑、追问沉默、问「有什么需求」 | 给二选一或具体小确认 |
| 用信息量替代判断 | 五套话术、一堆案例、长介绍 | 一次只给一条能直接发的消息 |

## 使用方式

每周复盘挑一条自己最容易犯的，只改这一条（31）。**不要**一次列五条改进项，改完整周都按这一处练。

## 禁忌

最忌讳**把这些反面案例当成「反面话术库」去记句子**。要记的是病因：一旦开始替对方做决定、要求他解释、或用数量掩盖不确定，措辞再漂亮也救不回来。
