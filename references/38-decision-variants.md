# 38 决策类异议：五种说法逐句拆解

> 补 [06-objection-decision.md](06-objection-decision.md)。核心动作永远是：把「买不买」换成一个能一句话回答的小确认。

## 一、先分清真决策与委婉收尾

| | 真决策 | 委婉收尾 |
|---|---|---|
| 记录里出现过 | 具体处境、合作类问题、决策人或时间点 | 全程没说过自己的事，回复越来越短 |
| 动作 | 给一个更小的下一步 | 给轻出口，不追、不问原因 |
| 后续 | 按他给的节点确认一次 | 转低频，见 44 |

分不清时按真决策处理**一次**，只用一个动作；动作之后对方仍不接，就按委婉收尾。判断依据只来自用户提供的原话，不靠「一般说考虑就是没兴趣」。

## 二、五种说法

### 1.「我考虑一下」

动作：给一个具体的小确认 + 一个由对方选的时间落点。

> 好，不急。
> 你先看 [范围里那一项] 对不对得上，有不合适直接说，我改一版。
> 我这边 [某个自然时间] 再跟你确认一次，方便吗？

末句要真的等对方回「方便」，没得到同意就不要当成约定。**不是**「你考虑好了告诉我」。

### 2.「要跟家人 / 合伙人商量」

动作：承认决策人存在，提供能转发的材料，不绕过他、不教他说服。

> 应该的，这笔是要一起定。
> 我把范围、交付和时间写成一页发你，直接转过去就行。
> 对方有想问的，你原话带给我，我按问题补，不用你转述一遍。

### 3.「再对比几家」

动作：不拦、不贬低，只留一个对齐口径的口子。

> 行，多看看是对的。
> 比的时候可以留意次数、含不含修改、最后拿到什么，这几项差得比较多。
> 有对不上的地方发我，我按实际范围说清楚。

### 4.「再看看 / 过阵子」

动作：不追问原因，把关系留在一个自然节点。

> 好，那先不占你时间。
> 到 [他说的那个时间] 前后我再问一句，那时候情况可能也更清楚。
> 中间有临时的变化，你随时发我就行。

### 5.「我没什么问题了」

动作：这句**不等于成交**，常意味着真实顾虑没被说出，或需求根本没确认。先问一句具体的小问题。

> 那我确认一处：[范围里这一项] 是你这次一定要的吗？
> 不是的话我去掉重给你一版。

别在这句之后直接推进定金（见 18 的误判案例 19）。

## 三、把大决定换成小确认：10 个替换

| 别问 | 换成 |
|---|---|
| 你考虑得怎么样了 | [范围里一项] 是不是这次一定要的 |
| 要不要定下来 | 先把 [开始时间] 占上，范围后面再调，可以吗 |
| 和家人商量好了吗 | 需不需要我把范围写成一页，方便你转过去 |
| 你什么时候能定 | [周四] 还是 [周五]，哪个方便 |
| 还有顾虑吗 | [A] 和 [B]，这次更想先做哪个 |
| 预算没问题吧 | 这版范围对得上你要的吗 |
| 你决定了吗 | 我先把 [材料清单] 发你，你看着准备就行 |
| 要不要再想想 | 你先看 [那一页]，有不合适直接改 |
| 怎么不回我了 | 上次说到 [他的原话]，这块我补一句 |
| 那我们就这么定 | 我按刚才说的定：[范围]、[时间]、交付 [东西] |

## 四、三件绝对不要做

1. **追问「你到底在顾虑什么」**：多数人说不清，只会得到「没什么」。
2. **制造紧迫**：这周名额满了、过了这周涨价、刚好有人在等这个时间——全是红线。
3. **主动降价**：把「考虑一下」当价格异议，是最常见也最难挽回的误判；对方会认为原价本来就不实。

另外别用一大段案例 / 利弊分析压过去。他要做决定，不是要更多阅读材料。

## 五、什么时候停

给过一次具体小确认，对方仍只回「好的」「嗯」「再说」，就停，不再追加消息，转 08 的低频触达。**止损不意味着放弃**：在他提过的那个时间点、他做过的事有新进展、或范围真的变了时，可以带真实由头再出现一次（见 44）。

## 六、输出要求

四段式第一段必须写清「这是真决策还是委婉收尾，依据是哪句原话」；第三段消息 短句连发 3-5 条；第四段写「发出去看他有没有回答那个具体问题」，禁忌从上面三件里挑最贴近的一件。

## 七、禁忌

最忌讳**把「考虑」当成需要更多说服材料的信号**。信息越多，决定越重；把决定拆小，才动得了。
