# 34 价格异议一：预算不够 / 这次拿不出

> 05 的第一分支。判断依据：对方提到预算、这个月、分期、要先留着别的开销，或明确说了一个数字上限。

## 一、这一类和「不值」完全不同

| | 预算不够 | 不确定值不值 |
|---|---|---|
| 他纠结的是 | 现金与时间点 | 拿到手的东西 |
| 有效动作 | 改范围 / 改节奏 / 分阶段 | 说清交付与边界（转 35） |
| 无效动作 | 反复讲价值、补案例 | 降价（降了仍在犹豫） |

分不清时用分类问句：

> 你说贵，是这次预算上不太方便，还是想先确认做出来大概是什么样？

## 二、四条可用路径（按让步程度排）

**路径 1｜缩小范围**：去掉一项，价格跟着变。
> 原先是 [两次 + 一版文档]，可以先只做第一次，把 [那一件事] 定下来，[调整后价格]。

**路径 2｜分阶段**：第一段小、可验证，后面按结果再决定。
> 先走第一段 [范围]，拿到 [一个小交付物]，[价格]。后面觉得需要再补第二段，按原来那版走。

**路径 3｜改节奏**：拉长周期、改成异步、减少同步次数。
> 不着急的话可以拉到 [周期]，同步改成 [形式]，价格按 [新范围] 算。

**路径 4｜按他的时间点回来**：不降价、不缩小，只把决定推迟到他提到的真实节点。
> 那先不动范围，到 [他说的时间] 前后我再跟你确认一次，可以吗？

**四条都要求写清「换掉了什么」**。同样范围少收钱是最差的一种让，见 27。

## 三、六种说法与接法

| 他说 | 别理解成 | 接法 |
|---|---|---|
| 「这个月预算不够」 | 要你降价 | 路径 4，或问下个月是否还作数 |
| 「能不能分期」 | 必须答应 | 按用户真实规则；没规则就说明需要他定，不临时编 |
| 「我只有 X」 | 要硬凑到 X | 按 X 反推能做的范围，做不了就如实说 |
| 「先做一半行不行」 | 半价做全部 | 明确第一段的交付物与价格 |
| 「别的地方也要用钱」 | 在暗示你贵 | 接住，回到时间与范围，不评价他的安排 |
| 「等发工资再说」 | 委婉拒绝 | 按他给的节点，之前不打扰 |

## 四、模板示例（非真实案例）

> 预算这块我明白了。
> 原先两次梳理加一版文档，可以先只做第一次，把 [那件事] 定下来，[调整后价格]。
> 后面觉得需要再补第二次，按原来那版走就行。
> 这样这次先不超你的预算，要不要先从第一步开始？

末句的「先不超你的预算」是复述他的话，不是施压；「要不要」给的是能回答的口子。**不要**写「我特别理解你现在不容易」这类揣测情绪的话。

## 五、价格带差异

- 百元级：预算类异议通常不值得改范围，直接给一个更轻的入口或等他回来。
- 千元级：缩小范围 / 分阶段最常用，写清少了哪一项。
- 万元以上：所谓「预算不够」常是「这么大一笔需要确认风险」，切入点是分阶段与一页范围（见 26），不是折扣。

## 六、常见错误

- 一听到预算就立刻降价。
- 为了凑到他给的 X，悄悄把交付物减少却不说明。
- 讲一堆「其实很划算」的价值论证。
- 替他安排分期方案（付款规则属于用户自己的经营规则）。
- 用「就差一点了」催他补差额。

## 七、禁忌

最忌讳**把预算问题谈成同情或施压**。既不渲染他的处境，也不暗示「这点钱都拿不出」。判断做对了的标志：对话从「多少钱」转到「先做哪一块、什么时候开始」。
