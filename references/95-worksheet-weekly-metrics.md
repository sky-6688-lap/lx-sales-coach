# 95 工作表：每周该看哪几个数字

> 补 [13-operations.md](13-operations.md)、[74-weekly-review-examples.md](74-weekly-review-examples.md)、[58-client-grading-and-time.md](58-client-grading-and-time.md)。一人公司不需要仪表盘，需要的是**每周固定看四列数字，并据此决定下周把时间放哪**。所有示例均为**模板示例（非真实案例）**。

## 一、周表模板（每周五填，10 分钟）

数字只填自己能数出来的，不估、不推测、不写「感觉」。

```text
【本周  第 __ 周】
新增对话数：        有实质来回的：
进入诊断的：        报过价的：
成交数 / 金额：     丢单数：
沉默超过 7 天的单：  下一步已过期的单：
本周发出消息条数：   得到回复的条数：
【四个比率】
报价率 = 报过价 / 有实质来回 =
成交率 = 成交 / 报过价 =
回复率 = 得到回复 / 发出消息 =
过期率 = 下一步已过期 / 在跟单 =
【一句话结论】这周真正卡住的一层是：
【下周只改一件事】：
```

## 二、四列数字分别诊断什么

比率不是拿来考核自己的，是拿来定位「卡在哪一层」。看一个下降的数字，就知道该翻哪一篇。

| 数字往下掉 | 大概率卡在 | 去查 |
|---|---|---|
| 新增对话少 | 内容没带来咨询 | [59-inbound-content.md](59-inbound-content.md) / [16-content-writing.md](16-content-writing.md) |
| 有来回但不进诊断 | 第一句没接住对方 | [01-value-and-positioning.md](01-value-and-positioning.md) / [23-first-contact-scenarios.md](23-first-contact-scenarios.md) |
| 诊断后不报价 | 需求没确认就急着讲方案 | [03-needs-diagnosis.md](03-needs-diagnosis.md) / [25-quote-timing.md](25-quote-timing.md) |
| 报价后不成交 | 异议层或价格结构 | [05-objection-price.md](05-objection-price.md) / [94-worksheet-offer-ladder.md](94-worksheet-offer-ladder.md) |
| 回复率低 | 消息太长、太像群发 | [19-message-style-rewrites.md](19-message-style-rewrites.md) / [15-message-checklist.md](15-message-checklist.md) |
| 过期率高 | 跟进没有节奏或没止损 | [08-follow-up-rhythm.md](08-follow-up-rhythm.md) / [44-stop-loss-and-reentry.md](44-stop-loss-and-reentry.md) |

**只挑一个最低的改**。同时改六处，等于一处都没改，下一周的数字也无法归因。

## 三、四周连起来看才有意义

单周波动说明不了什么（尤其单量小的时候）。四周表看的是方向，不是绝对值，见 [74-weekly-review-examples.md](74-weekly-review-examples.md)。

| 观察 | 含义 | 动作 |
|---|---|---|
| 报价率连涨、成交率连跌 | 报价太早或价格结构没接住 | 回头改 [25-quote-timing.md](25-quote-timing.md) |
| 成交率稳、新增对话连跌 | 交付没问题，前端在枯竭 | 排内容取材，见 [59-inbound-content.md](59-inbound-content.md) |
| 沉默单数连涨 | 跟进都堆在同一批单上 | 做止损与重启，见 [44-stop-loss-and-reentry.md](44-stop-loss-and-reentry.md) |
| 金额涨、条数涨、时间不够 | 该分级了 | [58-client-grading-and-time.md](58-client-grading-and-time.md) |

> 这周我只动一件事：[下周只改一件事]，其他先不动，下周看数字。

> 四周连着看，掉的是 [那个比率]，不是成交本身，先别改价格。

## 四、别看错的三个数

1. **不要看「粉丝数 / 阅读量」当成交指标**：它们和咨询之间隔着好几层，容易让人把时间花在错的地方。
2. **不要用「成交率」单独判断好坏**：单量小的时候，一单就能让它翻倍。连看四周，并同时看绝对单量。
3. **不要把「没回」记成「拒绝」**：沉默和拒绝是两回事，归因见 [45-silent-attribution.md](45-silent-attribution.md)、[31-lost-deal-attribution.md](31-lost-deal-attribution.md)。

**也不要编数据**：表里只填真实数得出来的。对外内容里更不能用这些数字当效果承诺，见 [21-boundaries-and-compliance.md](21-boundaries-and-compliance.md)。

## 五、从数字到动作：每周三件事

- **周一**：看 [93-worksheet-deal-card.md](93-worksheet-deal-card.md) 里「下一步已过期」和「状态停在 S4/S5 超一周」的单，只处理这两类。
- **周三**：把本周真实发生的客户原话补进卡片，挑一条最有代表性的做消息改写练习，见 [19-message-style-rewrites.md](19-message-style-rewrites.md)。
- **周五**：填周表 → 写一句结论 → 定下周只改的一件事 → 把这一件事拆成一个可发消息的动作，见 [96-worksheet-message-builder.md](96-worksheet-message-builder.md)。

## 六、时间分配那一列

数字最终要落到「下周时间放哪」。一个简单口径：把时间优先给「已报价未成交」和「已成交待交付」两类，其次给能带来咨询的内容，最后才给泛泛的新对话；具体分级见 [58-client-grading-and-time.md](58-client-grading-and-time.md)。低客单不要占用和万元单同样的跟进深度，见 [42-rhythm-by-price-band.md](42-rhythm-by-price-band.md)、[71-low-price-deals.md](71-low-price-deals.md)。

## 七、禁忌

1. 不填估算数、不把「感觉还行」写进数字列；不为让表格好看而改口径。
2. 不把周表里的数字当对外宣传的业绩证明，不编案例数据与效果承诺。
3. 不同时改六件事；不在单周波动后就推翻整套定价，见 [24-pricing-logic.md](24-pricing-logic.md)。
4. 不把沉默一律记为丢单、不把「在忙」当拒绝，也不因数字难看就加大群发。
5. 不记录与经营无关的个人隐私信息，见 [93-worksheet-deal-card.md](93-worksheet-deal-card.md) 的隐私边界。
