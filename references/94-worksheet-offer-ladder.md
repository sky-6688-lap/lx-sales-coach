# 94 工作表：产品阶梯与报价表

> 补 [24-pricing-logic.md](24-pricing-logic.md)、[26-proposal-templates.md](26-proposal-templates.md)、[02-pricing-and-quote.md](02-pricing-and-quote.md)。议价时最被动的人，往往不是不会谈，是**手上只有一个价**。这一篇给一张能填的阶梯表和一页能发的一页报价表。所有示例均为**模板示例（非真实案例）**。

## 一、阶梯模板（先填给自己看）

三档就够。每档只写三件事：解决到哪一步、给什么交付物、不包含什么。

```text
【起步档  价格 ____】
解决到：一个具体问题被说清 / 一份可用材料
交付物：
不含：
适合谁 / 不适合谁：
客户需要配合：

【主档  价格 ____】
解决到：从 [起点] 到 [终点] 的一段完整过程
交付物（含轮次）：
不含：
适合谁 / 不适合谁：
客户需要配合：

【深水档  价格 ____】
解决到：多轮 / 多人 / 更长周期
交付物（含节点）：
不含：
适合谁 / 不适合谁：
客户需要配合：
```

**三档的关系必须是「同一件事的不同深度」，不是三个不相干的产品**。否则客户问「便宜那档能不能加个 X」时，你只能现场发明一个档位。档位之间差价要有可说清的理由：轮次、周期、对象数量、交付物形态，四者之一，见 [24-pricing-logic.md](24-pricing-logic.md)。

## 二、一页报价表（可直接发给客户）

报价表对外只留客户做决定需要的信息，不写成本、不写工时、不写内部口径。

| 项目 | 内容 |
|---|---|
| 这轮解决什么 | 用客户自己的词写一句，见 [32-customer-language.md](32-customer-language.md) |
| 交付物 | 具体形态 + 数量 + 轮次 |
| 时间 | 起止 / 关键节点 |
| 不含 | 明确写一至两条 |
| 价格 | 数字 + 款项节点（定金 / 尾款），见 [49-deposit-rules.md](49-deposit-rules.md) |
| 需要你配合 | 材料、时间、确认人 |
| 变更规则 | 改期与加需求怎么算，见 [85-scope-creep.md](85-scope-creep.md) |
| 下一步 | 一个小动作，不写「考虑一下」 |

> 一页发你：解决什么、交付什么、价格和时间都在上面，需要你定的只有下一行。

> 不含的那两条我特意写上了，省得后面各自记一套。

## 三、三档怎么用在谈单里

阶梯不是让客户「挑便宜的」，是让「贵」这句话有地方落。

| 客户说 | 用阶梯的哪一格 | 一句话口径 |
|---|---|---|
| 太贵了 | 起步档 | > 不一定要整包，起步那档先把 [一件事] 说清，你看够不够。 |
| 预算只有一半 | 主档减范围 | > 预算按 [数字] 的话，我把 [某项] 拿掉，其余不变。 |
| 别家便宜 | 交付物对照 | 不比价格，比这页上的交付物，见 [36-competitor-comparison.md](36-competitor-comparison.md) |
| 能不能先试 | 起步档 | > 起步那档就是给试的，做完看结果再定后面。 |
| 要一次做全 | 深水档 | > 那就按深水档排节点，先定第一个节点对什么。 |

**让价必须换范围**，不能凭空抹零头，见 [27-discount-and-price-change.md](27-discount-and-price-change.md)。抹零头会让三档之间的理由全部失效，下一次客户还会从同一个位置砍。

## 四、填表时的四个校准

1. **起步档要真能独立交付**：不能是「主档砍一半、但做不出结果」的残次品。它的作用是低门槛验证，不是诱饵，见 [51-no-pressure-closing.md](51-no-pressure-closing.md)。
2. **主档是默认推荐**：报价时先给主档，别一次把三档全甩过去。三档并列会让客户只比较数字。
3. **「不含」必须写**：这一栏是后面所有范围争议的源头，见 [85-scope-creep.md](85-scope-creep.md)、[87-refund-and-dispute.md](87-refund-and-dispute.md)。
4. **低客单不要硬做三档**：百元级单用一档 + 清晰交付物就够，见 [71-low-price-deals.md](71-low-price-deals.md)。

## 五、涨价与老客户

阶梯调整时只对**新单**生效，写清生效日期，不追溯已成交的单；老客复联时的口径见 [53-renewal-and-price-change.md](53-renewal-and-price-change.md)、[91-dormant-client-revisit.md](91-dormant-client-revisit.md)。

> 这版阶梯 [日期] 起用，之前成交的不变。给你同步一下，免得下次对不上。

## 六、禁忌

1. 不编成本、工时、他人报价当定价依据；不写「市场价」「行业惯例」这类无法核对的说法，见 [21-boundaries-and-compliance.md](21-boundaries-and-compliance.md)。
2. 不承诺结果性收益（「一定带来 X 个客户」「保证涨多少」），受监管领域尤其不写。
3. 不虚构限时与稀缺，不用「今天定才这个价」逼单。
4. 不做同单不同价，不给熟人专属档，见 [89-referral-from-friends.md](89-referral-from-friends.md)。
5. 不在报价表里写内部备注、成本拆分或对同行的评价；对外那页要能被陌生人直接读懂，见 [90-multi-decision-makers.md](90-multi-decision-makers.md)。
