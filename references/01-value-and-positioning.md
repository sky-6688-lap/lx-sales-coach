# 01 把「我会什么」翻译成「你能得到什么」

> 状态 S0：对方还不知道你能帮他做成什么。也用于「一直被免费咨询、就是不下单」。

## 一、卡点通常不在专业，在表达顺序

多数人开口的顺序是：我是谁 → 我做过什么 → 我有哪些能力 → 所以你可以找我。这个顺序对同行有效，对客户无效。客户脑子里只有一件事：**我现在的麻烦，你能不能解决、要花我多少力气。**

把顺序倒过来：先说他眼下的处境，再说能变成什么样，最后才说你提供什么。资历只在对方已经有意向、需要降低风险时才补，而且只补一条最相关的。

## 二、三格句：一句话说清你卖什么

写不出一句话介绍，往往不是文案问题，是没选定「帮谁、解决什么」。用这三格填满，再压成一句话：

| 格 | 要填的 | 反例 |
|---|---|---|
| 谁 | 一个具体处境，不是人群标签 | 「职场人」「想成长的人」 |
| 从→到 | 从什么状态，变成什么状态 | 「提升能力」「赋能成长」 |
| 靠什么 | 你交付的具体东西 | 「全套方法论」「深度陪伴」 |

**填表示例（模板示例，非真实案例）**

- 谁：做过三份工作、说不清自己该往哪走的转行者
- 从→到：从「简历上一堆事但讲不出主线」到「能说清一个方向并拿出第一版作品」
- 靠什么：两次一对一梳理 + 一份可改的文档

压成一句：

> 我帮做过几份工作、讲不清主线的转行者，用两次梳理加一份文档，把经历收成一个能拿去投的方向。

注意这句里没有一个形容词在夸自己。判断标准很简单：**对方听完能不能立刻判断「这说的不是我」或「这说的就是我」**。如果听完是「哦，挺厉害的」，就是还没写对。

## 三、从卖点到买点：一张替换表

卖点是你付出的，买点是对方拿到的。写的时候把左列全部换成右列：

| 卖点（别这么写） | 买点（改成这个方向） |
|---|---|
| 三次一对一咨询 | 三次之后你会有一个能直接用的决定 |
| 我做了十年 | 这类情况我见过足够多次，能帮你少试两轮 |
| 全套体系 / 系统方法 | 不用自己拼，按步骤走就行 |
| 随时答疑 | 卡住当天就能问到，不用自己憋一周 |
| 陪跑 30 天 | 这 30 天有人盯着，不会做着做着就停了 |
| 赠送资料包 | 省掉你自己找模板的时间 |

**不要过度承诺**：买点写「能拿到什么」，不写「一定能拿到」。左列换成右列时，把「保证」「一定」「彻底」全部删掉。

## 四、首次开口：三句就够

第一次被问「你是做什么的」或刚加上微信，别发长介绍。三句结构：

1. 接住对方刚说的那句话（用他的词）
2. 一句三格句
3. 一个好回答的口子（是 / 否或二选一）

**模板示例（非真实案例）**

> 你刚说简历改了三版还是没回音，这块我确实常碰到。
> 我帮讲不清主线的转行者，用两次梳理把经历收成一个能投的方向。
> 你现在是卡在不知道选哪个方向，还是方向有了但写不出来？

第三句是关键：它把「听介绍」变成「说自己的事」，对话才能往下走。不要收在「有需要随时找我」——这句话等于把球丢回去，对方通常不会捡。

## 五、一直被免费问、不下单

这不是价格问题，是**边界没建立**：你每次都给完整答案，对方当然没有付费的理由。处理顺序：

1. 把「能免费答的」和「需要动手做的」分开，前者照常答，后者明确说要另约。
2. 第一次出现「你能不能帮我看看 / 给我做个方案」时，就报出形式与价格，不要拖到第三次。
3. 语气平，不翻旧账，不暗示对方占便宜。

**模板示例（非真实案例）**

> 这个方向我先说结论：你现在的卡点在第二步，不在简历本身。
> 具体怎么改要对着你的经历一条条过，这个得约一次正式梳理，[价格] 一次。
> 你看这周还是下周方便，我先留个时间？

## 六、常见错误

- **讲资历开场**：除非对方问，否则第一句不出现年限、证书、客户名单。
- **一次给全套**：把服务内容、流程、价格、案例一口气发完，对方只能回「好的我看看」。
- **用行业黑话**：对方没说过的词，一个都别用。
- **把「谁」写成人群标签**：越宽越没人认领。
- **把买点写成承诺**：「帮你拿到 offer」「一定涨薪」都属于红线。

## 七、禁忌

这个阶段最忌讳**用更多信息去压对方的不确定**。他没感觉的时候，补案例、补资质、补优惠都只会让对话更重。正确动作是缩小范围：问一个具体到他能一句话回答的问题。
