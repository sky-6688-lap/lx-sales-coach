# 65 30 天跟进日历（千元级已报价单示例）

> 把 42 的节奏矩阵、43 的三次分工、46 的消息库串成一条时间线。**模板示例（非真实案例）**，只演示排期逻辑；真实由头永远优先于表里的天数。

## 一、前提

- 价格带：千元级；已报价；对方最后一句是原话（有记录）。
- 门禁四项齐全，状态 S4（报价后沉默）。
- 三条硬约束：每次带新东西、不要求解释、不主动降价（41）。

## 二、日历

| 日 | 动作 | 判断 / 检查 | 该发的那条 |
|---|---|---|---|
| D0 | 报价三件套发出 | 数字是否和范围、交付、下一步一起给 | 见 63 的 12–15 条 |
| D0–D1 | **不补发任何解释** | 追加解释 = 替价格辩护 | 不发 |
| D1 | 记跟进三格 | 上次停在哪句 / 已给过什么 / 下次真实由头 | 不发 |
| D2 | 检查有没有真实由头 | 他提过的节点？我方范围变了？ | 有就提前，没有就等 D+3 |
| D3 | **第 1 次触达** | 补一条与他处境有关的信息，不提决定 | 「上次你说 [原话]，我后来想到一点：[信息]。不用回我」 |
| D4–D6 | 观察是否有实质回复 | 回答了具体问题 / 给了新信息 = 实质 | 有 → 立刻重判状态，不走 D10 |
| D7 | 周复盘（只挑这一单） | 看断点在哪，见 31 | 不发 |
| D10 | **第 2 次触达** | 给一个更小、更好答的选择 | 「先只做 [小第一步]，[价格]；或者按原版走。你更想先看哪一边？」 |
| D11–D13 | 观察 | 只回「嗯 / 好的」算无实质 | 不追加 |
| D14 | 检查第二次内容是否与第一次重复 | 重复就换由头，不发同一类信息 | — |
| D17 | 若有真实由头（他提过的节点、范围调整） | 优先于固定排期 | 按 44 的重新出现口径 |
| D21 | 无新东西 → **不发** | 「到点该发了」不是理由 | 不发 |
| D24 | **第 3 次触达（收尾）** | 交还节奏，不表现委屈 | 「那这事先放着，我不反复问了。想捡起来发我一句就行」 |
| D25–D30 | **止损** | 不再有第 4 次；不换渠道、不节日问候 | 不发 |
| D30+ | 只在四类真实理由下再出现 | 时间点到了 / 他的事有进展 / 我方范围真变了 / 他主动回来 | 见 44 |

## 三、三种打断日历的情况

1. **D3 之后他回了实质内容** → 立刻按新消息判状态，可能是 S3 异议或 S5 缺动作，不再走 D10。
2. **他明确说「暂时不需要」** → 立即止损，不走完三次。
3. **他给过时间点（「月底再看」）** → 三次压成一次，在那个时间点出现，第一句就提这个由头。

## 四、每一格发出前的四问

- 有没有一样他上次没见过的东西？
- 有没有要求他解释为什么没回？
- 有没有重复上一条？
- 占位符是否都替换了、能否直接复制？

四问有一项不过，就往后推，不凑数。

## 五、万元级怎么改

| 项 | 千元级 | 万元级 |
|---|---|---|
| 第 1 次 | 补一条信息 | 给一页范围，方便他转给决策人 |
| 第 2 次 | 范围二选一 | 分阶段第一步 + 验收项 |
| 节点 | D3 / D10 / D24 | 按他说的决策节点走 |
| 收尾 | 留门 | 留门 + 说明范围页仍在 |

**不因金额高就增加触达次数**。力度体现在材料更正式，不是发得更勤。

## 六、百元级怎么改

第 1 次之后若无回应，直接收尾，不做第 2、3 次。轻决策不值得占用跟进块的时间（见 58）。

## 七、常见错误

- 把日历当闹钟，到点就发。
- D0 当天补三条「补充说明」。
- 第 3 次之后「最后再试一次」。
- 用节日祝福填 D21 的空白。
- 他 D4 回了实质内容，你仍按 D10 发第二条。

## 八、禁忌

最忌讳**让排期覆盖对话**。他一开口，日历就作废；节奏服务于对话，不是反过来。
