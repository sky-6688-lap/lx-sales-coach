# 19 消息风格：20 组不合格 → 合格改写

> 把 SKILL.md 第六节六条规则落成可对照的样例。所有示例均为**模板示例（非真实案例）**，输出时须替换成用户提供的原词。

## 一、一条消息只做一件事（规则 1）

**例 1**
- ✗ 「不好意思打扰啦！上次那个方案您看了吗？如果预算不方便我们也能再商量，这周定的话还能按原价走～」
- ✓ 「上次那版范围，有一项要跟你确认：[具体项] 是这次一定要的吗？」
- 差在哪：原句同时做了唤醒、问预算、给折扣、造时限四件事，还带道歉与感叹号。

**例 2**
- ✗ 「我把服务内容、流程、价格、案例都发你，你看完有问题随时问我，不着急哈」
- ✓ 「先说这次做哪一块：[范围]。其余的等对上了再发，免得刷屏。」
- 差在哪：一次给全套，对方只能回「好的我看看」。

**例 3**
- ✗ 「你这情况我觉得得先梳理再动手，另外价格我也可以给你算一版」
- ✓ 「先定一件事：这轮只做 [范围]，可以吗？」

## 二、用客户自己说过的词（规则 2）

**例 4**
- ✗ 「我们的赋能体系可以帮你完成认知升级」
- ✓ 「你说『改了三版还是没回音』，这轮就处理这一句。」

**例 5**
- ✗ 「通过标准化交付物实现闭环」
- ✓ 「做完你会拿到一份能直接改的 [文档名]。」

**例 6**
- ✗ 「针对您的痛点提供定制化解决方案」
- ✓ 「你刚说卡在 [他的原话]，这块我按你的情况对一遍。」

## 三、结尾留好回答的口子（规则 3）

**例 7**
- ✗ 「你考虑好了跟我说」
- ✓ 「[周四] 还是 [周五]，哪个方便？」

**例 8**
- ✗ 「有什么想法随时交流」
- ✓ 「[范围里这一项] 要不要保留？回我一个『留』或『去掉』就行。」

**例 9**
- ✗ 「你看看还有哪里不清楚」
- ✓ 「是卡在 [A]，还是 [B]？」

**例 10**
- ✗ 「期待你的反馈」
- ✓ 「这版范围对得上你要的吗？对不上我改一版。」

## 四、不道歉铺垫、不连环追问、不用感叹号（规则 4）

**例 11**
- ✗ 「不好意思又来打扰你了！」
- ✓ 直接说事，第一句就是内容。

**例 12**
- ✗ 「在吗？方便吗？现在聊两句可以吗？」
- ✓ 一条消息说完事，不等「在吗」的回复。

**例 13**
- ✗ 「太好了！那我们赶紧定下来吧！」
- ✓ 「那按这版定，我 [时间] 把范围页发你。」

**例 14**
- ✗ 「是不是我哪儿没说明白？还是价格的问题？或者你最近比较忙？」
- ✓ 「上次说到 [他的原话]，这块我补一句：[具体信息]。不用回我。」

## 五、不施压、不替客户做决定（规则 5）

**例 15**
- ✗ 「这个价今天不定，下周就调了」
- ✓ 「价格按 [范围] 定，你什么时候定都不影响这版范围。」

**例 16**
- ✗ 「我觉得你直接上第二次就够了，别犹豫了」
- ✓ 「两种都可以：[小一版] 或原版。你更想先看哪一边？」

**例 17**
- ✗ 「这个机会错过就没了」
- ✓ 删掉整句，只留事实与下一步。

**例 18**
- ✗ 「别人都这么做，你这样会走弯路」
- ✓ 「按你这情况，先做 [动作一]，卡住的地方通常在 [动作二]。」

## 六、长度与可复制性（规则 6）

**例 19**
- ✗ 「你可以先表达一下理解，然后说明这次的范围，最后约个时间，语气别太硬」
- ✓ 「范围我按 [范围] 定，交付 [东西]。[周四 / 周五]，哪个方便？」
- 差在哪：前者是给 AI 的指令，不是给客户的消息。

**例 20**
- ✗ 一段 180 字、含三个问号、两个括号补充说明
- ✓ 拆成两条：一条给信息，一条给二选一；每条 ≤60 字为主。

## 七、怎么自查

改完读一遍：能不能直接复制粘贴？有没有一个字需要用户自己改？有没有一处是在要求对方解释？三条里有一条命中，就回到对应规则重改。

**不要**把这份改写表当成「同义词替换词典」。风格规则的底层是**少替对方做决定、少要求对方付出解释成本**；只换词不改结构，读起来还是一样重。

## 八、禁忌

最忌讳「改了语气没改结构」：把「您」换成「你」、加两个语气词，仍然一段塞三件事，这类消息照样发不出去。
