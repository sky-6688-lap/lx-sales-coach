# 19 消息风格：20 组不合格 → 合格改写

> 把 SKILL.md 第六节六条规则落成可对照的样例。所有示例均为**模板示例（非真实案例）**，输出时须替换成用户提供的原词。

## 一、一条消息只做一件事（规则 1）

**例 1**
- ✗ 「不好意思打扰啦！上次那个方案您看了吗？如果预算不方便我们也能再商量，这周定的话还能按原价走～」
- ✓ 「上次那版范围，有一项要跟你确认：[具体项] 是这次一定要的吗？」
- 差在哪：原句同时做了唤醒、问预算、给折扣、造时限四件事，还带道歉铺垫与限时施压。

**例 2**
- ✗ 「我把服务内容、流程、价格、案例都发你，你看完有问题随时问我，不着急哈」
- ✓ 「先说这次做哪一块：[范围]。其余的等对上了再发，免得刷屏。」
- 差在哪：一次给全套，对方只能回「好的我看看」。

**例 3**
- ✗ 「你这情况我觉得得先梳理再动手，另外价格我也可以给你算一版」
- ✓ 「先定一件事：这轮只做 [范围]，可以吗？」

## 二、用客户自己说过的词（规则 2）

**例 4**
- ✗ 「我们的赋能体系可以帮你完成认知升级」
- ✓ 「你说『改了三版还是没回音』，这轮就处理这一句。」

**例 5**
- ✗ 「通过标准化交付物实现闭环」
- ✓ 「做完你会拿到一份能直接改的 [文档名]。」

**例 6**
- ✗ 「针对您的痛点提供定制化解决方案」
- ✓ 「你刚说卡在 [他的原话]，这块我按你的情况对一遍。」

## 三、结尾留好回答的口子（规则 3）

**例 7**
- ✗ 「你考虑好了跟我说」
- ✓ 「[周四] 还是 [周五]，哪个方便？」

**例 8**
- ✗ 「有什么想法随时交流」
- ✓ 「[范围里这一项] 要不要保留？回我一个『留』或『去掉』就行。」

**例 9**
- ✗ 「你看看还有哪里不清楚」
- ✓ 「是卡在 [A]，还是 [B]？」

**例 10**
- ✗ 「期待你的反馈」
- ✓ 「这版范围对得上你要的吗？对不上我改一版。」

## 四、说「咱们」、语气词用够、反问确认收尾；不道歉铺垫、不连环追问（规则 4）

**例 11**
- ✗ 「不好意思又来打扰你了！」
- ✓ 直接说事，第一句就是内容。

**例 12**
- ✗ 「在吗？方便吗？现在聊两句可以吗？」
- ✓ 一条消息说完事，不等「在吗」的回复。

**例 13**
- ✗ 「太好了！那我们赶紧定下来吧！」
- ✓ 「那按这版定，我 [时间] 把范围页发你。」

**例 14**
- ✗ 「是不是我哪儿没说明白？还是价格的问题？或者你最近比较忙？」
- ✓ 「上次说到 [他的原话]，这块我补一句：[具体信息]。不用回我。」

## 五、不施压、不替客户做决定（规则 5）

**例 15**
- ✗ 「这个价今天不定，下周就调了」
- ✓ 「价格按 [范围] 定，你什么时候定都不影响这版范围。」

**例 16**
- ✗ 「我觉得你直接上第二次就够了，别犹豫了」
- ✓ 「两种都可以：[小一版] 或原版。你更想先看哪一边？」

**例 17**
- ✗ 「这个机会错过就没了」
- ✓ 删掉整句，只留事实与下一步。

**例 18**
- ✗ 「别人都这么做，你这样会走弯路」
- ✓ 「按你这情况，先做 [动作一]，卡住的地方通常在 [动作二]。」

## 六、长度与可复制性（规则 6）

**例 19**
- ✗ 「你可以先表达一下理解，然后说明这次的范围，最后约个时间，语气别太硬」
- ✓ 「范围我按 [范围] 定，交付 [东西]。[周四 / 周五]，哪个方便？」
- 差在哪：前者是给 AI 的指令，不是给客户的消息。

**例 20**
- ✗ 一段 180 字、含三个问号、两个括号补充说明
- ✓ 短句连发 3-5 条：一条给信息，一条给二选一，一条反问确认收尾；单条不超过 3 行。

## 七、怎么自查

改完读一遍：能不能直接复制粘贴？有没有一个字需要用户自己改？有没有一处是在要求对方解释？三条里有一条命中，就回到对应规则重改。

**不要**把这份改写表当成「同义词替换词典」。风格规则的底层是**少替对方做决定、少要求对方付出解释成本**；只换词不改结构，读起来还是一样重。

## 八、禁忌

最忌讳「改了词没改结构」：换了称呼、加了语气词，仍然一段塞三件事，这类消息照样发不出去。按原版明文，语气词和「咱们」该用就用，问题在结构不在语气词。

## 九、温和语气：6 组补充改写（规则 17）

前二十组改的是结构，这六组改的是对方读完的感受。三版逐版适用，尤其 C 版。

**例 21 否定客户的判断**
- ✗ 「其实不是贵，是你还没看到价值」
- ✓ 「你说贵，我记下了，先把 [范围] 说清」
- 差在哪：前句先判他错了，后句只补事实。

**例 22 质问动机**
- ✗ 「为什么不买，是哪里不满意？」
- ✓ 「这块先放着你这边，不用急着回」
- 差在哪：把解释成本从客户身上拿走。

**例 23 拿免费的东西比较**
- ✗ 「免费的肯定不好用，功能差很多」
- ✓ 「免费的确实不少，够用就先用」
- 差在哪：不贬低，也不替他下结论。

**例 24 催促与硬时限**
- ✗ 「这周不定下周就调价了，尽快回我」
- ✓ 「什么时候定都不影响这版范围」
- 差在哪：删掉时限，只留事实。

**例 25 评价情绪 / 教育口吻**
- ✗ 「你别激动，听我把道理讲完」
- ✓ 「让你不舒服了，这句我先接住」
- 差在哪：不评价、不教育、不要求对方配合。

**例 26 句首硬转折与甩锅**
- ✗ 「但是这次范围不能加，规则就是这样」
- ✓ 「新增的 [需求] 不在 [范围] 里，我另列一版」
- 差在哪：把边界写成可核对的一版，而不是顶回去。

**怎么自查**：三版并排读，问自己「客户正带着火气看到这句，会不会觉得被纠正、被催、被比较、被教育」。任一为是，回到 [98 篇](98-warm-tone-redlines.md) 的替换表重写；温和不是拿降价换和气；原版的语气词、「咱们」、先看见人再谈事本身就是温和。
