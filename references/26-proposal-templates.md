# 26 一页提案：3 个行业模板与漏项清单

> 补 [02-pricing-and-quote.md](02-pricing-and-quote.md) 第四节。只在对方已认可范围、需要书面确认时使用。所有内容为**模板示例（非真实案例）**。

## 一、六块结构（不变）

```
1. 我理解你要解决的：[用对方原话，一句]
2. 这次做完你会拿到：[1–3 条可交付物]
3. 具体怎么做：[阶段 / 次数 / 时间]
4. 需要你配合的：[材料、时间、决策人]
5. 不包含：[明确写出]
6. 费用与下一步：[价格、方式、一个可确认的动作]
```

六块必须一页装得下。写不进一页，说明范围还没收敛，先回到需求确认句，不要靠加页解决。

## 二、模板 A｜千元级一对一梳理

```
1 你要解决的是：「改了三版简历，投出去还是没回音，自己看不出问题在哪」。
2 做完你会拿到：一份逐行标注的修改建议、一版可直接投稿的主线说明。
3 怎么做：第一次 60 分钟逐行过，我出标注版；三天内你改一版发我；
  第二次 40 分钟对改稿，当场定稿。全程两周内。
4 需要你配合：现有简历、最近投过的三个岗位、两次沟通时间。
5 不包含：代写全文、投递代操作、面试陪同、岗位推荐。
6 费用 [价格]，确认后我发收款方式；这版范围没问题的话，
  我把第一次时间定在 [日期]，可以吗？
```

## 三、模板 B｜万元级分阶段方案

```
1 你要解决的是：「团队第一次外包，说不清做到什么算好」。
2 做完你会拿到：一份可写进合同的验收清单、阶段性交付物 [三项]、一次复盘结论。
3 怎么做：分两段。第一段 [周期] 出范围与验收项；确认后再进第二段 [周期] 交付。
  每段结束有一次书面确认。
4 需要你配合：指定一位对接人、[材料]、每段确认不超过 [天数]。
5 不包含：第二段之后的持续运维、原系统改造、第三方采购费用。
6 第一段 [价格]，第二段确认范围后另报。先确认第一段的验收项，
  我 [日期] 发第一版清单给你，可以吗？
```

**万元级的关键不是写得更长，是把「先做哪一段」写清楚**。分阶段是降低风险的合法方式，比任何保证都实在。

## 四、模板 C｜交付物型 / 代做类

```
1 你要解决的是：「活动下周要用，主视觉还没定」。
2 做完你会拿到：[主视觉一版]、[两处尺寸的适配文件]、一版可改源文件。
3 怎么做：[日期] 前出初稿，含一轮修改；[日期] 定稿。
4 需要你配合：文字内容、品牌基础规范、一次确认时间。
5 不包含：额外轮次的修改、印刷落地、其他物料延展。
6 费用 [价格]，含一轮修改。这版范围确认后我 [日期] 出初稿，可以吗？
```

代做类最容易在第 5 块吃亏：**「含几轮修改」必须写数字**，写「满意为止」等于把边界交给对方定义。

## 五、12 项漏项检查

- [ ] 第 1 块用的是对方原话，不是我概括的术语
- [ ] 交付物有形态（文档 / 文件 / 次数），不是「支持」「赋能」
- [ ] 时间写的是具体周期或日期，不是「尽快」
- [ ] 写了需要对方配合什么
- [ ] 写了不包含什么
- [ ] 修改轮次有数字
- [ ] 决策人 / 对接人明确
- [ ] 价格与对应范围绑在一起
- [ ] 付款方式只写用户确认过的
- [ ] 下一步是一个能回答是或否的动作
- [ ] 没有出现保证、一定、包过等承诺
- [ ] 没有第三方人名、机构名、外部链接

## 六、什么时候发

| 时机 | 发不发 |
|---|---|
| 对方已认可范围、问「能不能写下来」 | 发 |
| 万元级需要共同决策 | 发（给能转发的一页） |
| 对方只是问价、没说自己的事 | 不发，先回范围确认 |
| 对方要求「先出完整方案看看」 | 不发成品方案，只发这一页范围 |
| 已经报完价、对方在沉默 | 不主动补发提案，按 46 处理 |

提案是**确认工具**，不是说服材料。对方还在犹豫要不要做时发提案，只会多一份没人看的文件。

## 七、常见错误

- 加公司介绍、团队履历、愿景，六块变十块。
- 第 5 块留空或写「其他双方协商」。
- 把价格放在最后一页单独一行。
- 用「最终解释权」这类含糊表述替代明确边界。
- 提案发完立刻追问「看得怎么样」。

## 八、禁忌

最忌讳**用提案替用户承诺没定过的规则**（定金退还、退款条件、效果保证）。规则没定就留空并说明由用户自己定，见 [49-deposit-rules.md](49-deposit-rules.md)。
