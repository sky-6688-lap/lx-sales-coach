# 47 跟进 20 个常见错误与改写

> 和 [19-message-style-rewrites.md](19-message-style-rewrites.md) 的分工：那篇管通用消息风格，这篇只管跟进场景。示例均为**模板示例（非真实案例）**。

## 一、催决定类（1–5）

**1** ✗ 「考虑得怎么样了？」→ ✓ 「[范围里一项] 是这次一定要的吗？」
**2** ✗ 「上次那版您看了吗？」→ ✓ 「上次你说 [原话]，这块我补一句：[新信息]」
**3** ✗ 「什么时候能定呀」→ ✓ 「[周四] 还是 [周五]，哪个方便？」
**4** ✗ 「有进展了记得告诉我」→ ✓ 「我 [他给的时间点] 再问一句，方便吗？」
**5** ✗ 「要不要我再发一遍资料」→ ✓ 不发，等有一样新东西再说。

## 二、要求解释类（6–9）

**6** ✗ 「是不是我哪里没说清楚？」→ ✓ 「用得上先看着，不用回我。」
**7** ✗ 「怎么一直没回呀」→ ✓ 删掉整句，只留有用信息。
**8** ✗ 「是价格的问题吗？」→ ✓ 「你说贵，是预算上不方便，还是想先确认做出来是什么样？」（仅在对方说过「贵」时用）
**9** ✗ 「你是不需要了吗」→ ✓ 「这边已经定了或者不弄了，回我一句就行。」

## 三、情绪与铺垫类（10–13）

**10** ✗ 「不好意思又打扰了！」→ ✓ 直接说事，第一句就是内容。
**11** ✗ 「不打扰了哈，就是想问一句…」→ ✓ 删掉前半句。
**12** ✗ 「也不知道你最近忙不忙」→ ✓ 不揣测，直接给信息。
**13** ✗ 「我等了几天也没好意思问」→ ✓ 不写自己的等待，只写这一条的内容。

## 四、施压与虚假由头类（14–17）

**14** ✗ 「这周不定就要调价了」→ ✓ 删掉；有真实排期变化才提，且不带后果暗示。
**15** ✗ 「刚好有个空位空出来了」→ ✓ 用真实由头：「上次你说 [时间点]，我按这个来问一句」。
**16** ✗ 「刚好想起你」→ ✓ 「上次你说到 [原话]，这块我补一句」。
**17** ✗ 「别人都定完了，就差你了」→ ✓ 删掉整句；不比较、不暗示。

## 五、内容与节奏类（18–20）

**18** ✗ 三条跟进都是同一句，只换开场白 → ✓ 每次带一样他没见过的东西（41）。
**19** ✗ 节日祝福、群发问候当触达 → ✓ 没有新东西就不发。
**20** ✗ 第 3 次之后又来「最后一次」→ ✓ 直接停；重启只靠真实理由（44）。

---

## 六、错误背后的四个共同原因

| 原因 | 表现 | 修正 |
|---|---|---|
| 把跟进当作提醒 | 只在问「看了吗」 | 改成提供判断依据 |
| 把沉默当成需要解释的事 | 追问原因 | 改成不要求解释 |
| 用数量替代由头 | 到点就发、多发几次 | 改成「无新东西不发」 |
| 把焦虑写进消息 | 道歉、等待、委屈 | 改成只写事实与下一步 |

## 七、一条快速自检

发之前把消息里所有句子分成两类：**对他有用的**、**关于我这边的**。跟进消息里第二类最好一句都没有。「我这几天一直在想你这单」「我们这边最近调整了」——除非调整的是与他有关的范围，否则都属于自说自话。

## 八、禁忌

最忌讳**把「勤」当成跟进质量**。一天一条、连发一周，看起来很努力，实际是把「在忙」推成「不想回」。真正的跟进质量只看一件事：这一条有没有让对话比上一条多出一点可判断的信息。
