# 58 客户分级与三块时间

> 补 [13-operations.md](13-operations.md)。分级只为分配时间，不给人贴标签，也不对客户说。

## 一、两个维度，都看可观察事实

| 维度 | 看什么 |
|---|---|
| **处境明确度** | 有没有说过自己具体卡在哪、不解决会怎样 |
| **决策路径清晰度** | 有没有说过谁定、什么时候定、钱从哪来 |

| 类 | 信号 | 时间动作 |
|---|---|---|
| **A** 两项都清楚 | 有原话、有节点 | 优先排正式沟通、写范围页、按节点跟进 |
| **B** 处境清楚、路径不清 | 聊得投入，但没说过谁定 / 何时定 | 一次确认决策路径，之后低频触达 |
| **C** 两项都不清 | 只问价、只问「怎么做的」、替别人问 | 正常回一两句，不写方案、不排跟进表 |

**C 不等于「不值得」**，只是这周不投入制作时间。有人从 C 变 A 很常见（见 29），所以记录保留、门留着。

**不要按客单价给人分三六九等**。金额是价格带的输入，不是对人的评价。

## 二、三块时间

| 块 | 做什么 | 频率 |
|---|---|---|
| **谈单块** | A 类的正式沟通、范围页、报价 | 每周固定 2–3 个整块 |
| **跟进块** | 按 42 的节奏集中处理 B 类与沉默单 | 每周 1–2 次，不随时插 |
| **内容块** | 写一条能带来咨询的内容（见 59） | 每周 1 次 |

三条配套：

1. 跟进块先看「已经给过什么」，避免重复（30 的跟进三格）。
2. 谈单块只做 A 类；C 类的消息统一在跟进块回。
3. 每周留一次复盘：只挑一单，看断点在哪（31），不盘全部。

**不承诺**「这样做就能提升转化率」。这是把注意力放回可控动作，不是效果保证。

## 三、多单并行四条提醒

- 同一周不要给两个客户发同一段跟进；由头与内容按各自记录生成。
- 范围页、报价句可以模板化，**客户原话不能模板化**（见 32）。
- 老客与新客的时间不要全给新客：交付期节点见 52。
- 每单只保留一张诊断四格，别在多个地方记不同版本。

## 四、周经营表（填空即可）

```
本周 A 类：__ 单 → 排在谈单块
本周 B 类：__ 单 → 一次确认路径后低频
本周 C 类：__ 单 → 只回一两句
跟进块发出：__ 条（逐条检查是否带新东西）
止损：__ 单（写明真实理由）
本周复盘：挑 1 单，断点 = __，下次改 1 处 = __
```

## 五、没人来问时的检查顺序

1. 内容是不是在「播报」而不是「对话」？（59）
2. 三格句是不是写了人群标签而不是具体处境？（22）
3. 结尾有没有给一个具体、能一句话回的口子？
4. 有没有把 C 类当成 A 类，把时间耗在不会定的单上？

## 六、六个常见错误

- 把所有沉默单都当成要重点抢救，A 类反而没时间。
- 用「每天发三条」当内容计划，产出同质内容。
- 把分级结果说给客户听，或写进对外内容。
- 用表格、日历、系统替代判断：工具只是承载。
- 一周盘全部单子，结果一处也没改。
- 按金额排序，忽略处境与决策路径。

## 七、禁忌

最忌讳**用工具去掩盖判断**。真正决定时间分配的仍是那两句：他有没有说过自己的处境、有没有说过怎么定。这两条没有，就别投入制作时间，表填得再满也一样。
