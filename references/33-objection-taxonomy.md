# 33 异议总纲：四类来源、分流树与复合异议

> 05 / 06 / 07 的总入口。遇到「说不清是哪类」「一句话里夹了两种阻力」时先读这一篇。

## 一、异议不是拒绝，是一句还没被接住的话

对方愿意说出阻力，通常比沉默更好处理。第一动作永远是**接住并分类**，不是解释、不是降价、不是补案例。

四类来源：

| 类 | 他真正在问 | 典型说法 | 去哪篇 |
|---|---|---|---|
| **价格类** | 这笔钱怎么算 / 值不值 | 贵、砍价、预算、别家便宜 | 34 / 35 / 36 / 37 |
| **决策类** | 这事谁定、什么时候定 | 考虑、商量、对比、再看看 | 38 |
| **信任类** | 交给你会怎样 | 万一没用、没听过、要案例 | 39 |
| **边界类** | 能不能先免费拿到 | 一直白问、先出方案 | 40 |

**注意**：四类不是按关键词硬分。「有点贵」可能是预算（价格），也可能是「不确定值不值」（信任）；「考虑一下」可能是决策路径，也可能是没说出口的信任缺口。分类靠一句追问，不靠词面。

## 二、分流树

```
对方明确说了阻力？
├─ 否 → 不是异议，回 00-router 重判状态（可能是 S0/S4/S5）
└─ 是
   ├─ 出现「钱 / 价 / 预算 / 别家」 → 先问一句分类（34）
   │   ├─ 预算 → 34
   │   ├─ 不值 → 35
   │   ├─ 比价 → 36
   │   └─ 试探砍价 → 37
   ├─ 出现「定 / 商量 / 对比 / 再看」 → 38
   │   └─ 若背后是怕没效果 → 转 39
   ├─ 出现「效果 / 保证 / 案例 / 做过吗」 → 39
   └─ 出现「先给我看看 / 帮我做个…」但没提钱 → 40
```

## 三、分类问句（通用一句）

> 你说 [他的原话]，是 [A 具体可能]，还是 [B 具体可能]？我按这个说，不然容易说偏。

这是整个异议层最有用的一句。它把模糊的阻力拆成两个能一句话回答的选项，且**不要求对方解释情绪**。用户提供的原话越具体，A/B 越具体；不具体就走门禁补原话，不自己编两个选项。

## 四、复合异议：三种常见组合

| 组合 | 主 / 辅 | 处理顺序 |
|---|---|---|
| 「有点贵」+ 报价后沉默 | 主价格，辅沉默（S4） | 先接异议分类，再谈节奏；不把沉默判成拒绝，也不主动降价 |
| 「考虑一下」+「能不能分期」 | 主价格，辅决策 | 先分类是预算还是不值；给最小下一步，不催决定 |
| 「先出个方案」+「万一没效果呢」 | 主边界，辅信任 | 先给一页范围（不是成品方案），再补可核对的交付与不确定部分 |

**规则**：取**会阻断推进**的那个当主状态，另一个最多辅读一篇。一次只输出针对主状态的那一版消息，不两套话术并列给用户挑。

## 五、接住异议的三段结构

1. **接住**（不反驳）：用他的词复述一句，不加「但是」。
2. **分类或补可核对的事实**：一句问清，或把交付、边界、需要配合的事说清。
3. **一个好答的口子**：是 / 否、二选一、一个小动作。

**不要**在这三段里塞：成本解释、别人都这样、一堆案例、立刻降价、限时。

## 六、六个通用禁忌

1. 把「贵」直接当成降价请求。
2. 把「考虑一下」当成拒绝，立刻收尾。
3. 用「其实不贵」开场。
4. 追问「你到底在顾虑什么」。
5. 用一大段好评 / 案例压过去。
6. 三轮还停在同一个词上——说明分类没做对，退回分类问句。

## 七、输出要求

四段式的第一段必须写清：这是哪一类、依据是哪句原话、若为复合异议主辅分别是什么。第二段说明为什么先处理主状态。第三段只给一条当前该发的消息。第四段的禁忌从上面六条里挑最贴近的一条。
