# 56 口碑素材：授权、脱敏与归档

> 补 [11-after-sale.md](11-after-sale.md) 第五节、[16-content-writing.md](16-content-writing.md) 的取材规则。没有授权，就没有可用的案例。

## 一、三条硬规则

1. **先问能不能用、以什么形式用**：是否匿名、能不能截图、用于哪些地方（朋友圈 / 页面 / 文档）。对方说不行就不使用，不换个说法绕过去。
2. **脱敏**：去掉姓名、公司、联系方式、金额、可识别的项目细节；只保留与结果有关的事实。
3. **不加工成夸大宣传**：不把「感觉清楚多了」改成「效果立竿见影」，不补数字、不补没说过的结论。

## 二、授权怎么问

一次问清三件事，别分三次：

> 你刚说的那句我想留着用一下，先问清楚：
> 能不能匿名引用？截图要不要打码？只放在 [使用范围] 可以吗？
> 不方便就完全不用，不影响咱们这轮。

三条分别对应：形式、脱敏程度、使用范围。「不方便就完全不用」要真的算数，不追第二遍。

## 三、可沉淀的四类素材

| 类型 | 能留什么 | 不能留 |
|---|---|---|
| 一句主动反馈 | 对方原话（脱敏后） | 把它改写成更强的结论 |
| 一个过程节点 | 「第几次做完拿到了什么」 | 编造前后对比数字 |
| 一份前后变化 | 可观察的事实 | 身份信息、金额 |
| 一个被问过的问题 | 问题本身（去掉提问者） | 私下聊天原文整段 |

## 四、脱敏替换表

| 原文里可能出现 | 改成 |
|---|---|
| 姓名 / 昵称 | 「一位客户」「有人」 |
| 公司 / 部门 / 项目名 | 「某小团队」「一个项目」 |
| 具体金额 | 删掉，或写成价格档 |
| 时间精确到某日 | 「两周左右」 |
| 聊天截图里头像与账号 | 全部打码；不确定就只用文字 |
| 第三方（同事、家人、合作方）信息 | 整段删除 |

**截图风险最高**：即使打了码，排版、时间、上下文也可能被认出来。没把握就只用一句脱敏后的文字，不用图。

## 五、素材归档四格

```
原话（脱敏后）：
授权范围：[匿名 / 可截图 / 使用位置]
可用到什么时候：[如对方给过时限]
不可用部分：[哪句不能用]
```

归档进 [61-content-templates.md](61-content-templates.md) 的取材表，出文案时按「授权范围」取用，不混用不同客户的句子。

## 六、素材不足时

如实说「目前还没有可以公开的案例」，改用可核对的交付与边界（见 39）。**不要**拿模板示例冒充实战，不要用「很多客户都…」这类模糊背书。

## 七、六个常见错误

- 把「客户挺满意」当成同意公开。
- 先发出去，再回头补问授权。
- 脱敏只改名字，公司、金额、项目细节全留着。
- 把一句反馈改写成广告语，意思变了。
- 不同客户的话拼成一条「案例」。
- 用未授权的截图当海报配图。

## 八、禁忌

最忌讳**把别人的信任当成自己的素材库**。素材能不能用，只有对方说了算；这一条没有「差不多可以」的中间地带。
