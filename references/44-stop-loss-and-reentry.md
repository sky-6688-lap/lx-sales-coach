# 44 止损线与重新出现的真实理由

> 补 [08-follow-up-rhythm.md](08-follow-up-rhythm.md) 第四节。止损不是放弃，是停止无由头的出现。

## 一、三条止损线（命中任一条即停）

1. **三次触点后仍无实质回复**：只回表情、嗯、好的、收到，都算无实质。
2. **对方明确说「暂时不需要」「先不弄了」**：不再设计「再解释一次」的话术。
3. **用户自己判断不值得再投入时间**：直接停，不需要向对方宣告。

止损时**直接停**，不用再发一条「那我就不打扰了」——第 3 次触点的收尾已经说过了。再发一条，反而变成第 4 次。

## 二、止损不做的四件事

- 不发「最后一次试试」。
- 不换渠道（微信不回改短信、改群聊 @）。
- 不用节日祝福、群发问候维持存在感。
- 不编由头（「刚好有个空位」「今天最后一天」）。

跟进次数越多，前面所有消息的语气越像施压；留一条干净的收尾，比多一次触达更有价值。

## 三、止损后记三格

```
停在哪句（他的原话）：
已给过什么：
可以再出现的真实理由 / 时间（没有就写「暂无」）：
```

第三格是唯一能重启这单的入口。写「暂无」就真的不再出现，不靠感觉找机会。

## 四、可以再出现的四类真实理由

| 类型 | 例子 | 第一句怎么写 |
|---|---|---|
| **他给过的时间点到了** | 「下个月再看」「季度结束再说」 | 「上次你说 [时间] 再看，我按这个来问一句」 |
| **他提过的事有新进展** | 他做过的事、他要等的节点有结果 | 「你之前提到 [他的原话]，这块现在有变化吗？」 |
| **你这边范围真的变了** | 新增/去掉了某项、价格档调整、有新的小一版 | 「我这边范围调了一版，跟你同步一下：[变化]」 |
| **他主动回来** | 发来一句、问了个问题 | 立刻按新消息判状态，不按旧排期 |

四类都满足 41 的三个判据：来自记录、可核对、不依赖巧合。

**不算理由**：想起来了、这个月业绩差、节日到了、看到他发了朋友圈、刚好有个名额。

## 五、重新出现的第一句

> 上次你说 [他的原话 / 时间点]，我按这个来问一句。
> [一条与那件事有关的新信息，不推销]
> 要是这边已经定了或者不弄了，回我一句就行，我不反复问。

第三句给了一个特别容易回的出口（「已经定了」），对方不必解释、不必道歉。这比「考虑得怎么样了」好回得多。

## 六、四种「不该重启」的情况

1. 对方明确说「不用了，谢谢」——除非他主动回来。
2. 交付期出过问题、还没处理完——先处理交付，不谈新单。
3. 用户自己都记不清这单聊到哪——先补记录，别凭印象发消息。
4. 只是想「再试试」——没有真实理由就不发。

## 七、常见错误

- 把止损理解成「拉黑/放弃」，于是干脆不留记录。
- 三个月后群发一条问候，当作「重新出现」。
- 重启第一句不提旧由头，让对方觉得莫名其妙。
- 重启时顺便把价格降了，用折扣当由头。
- 对方主动回来，却仍按 D+10 的排期回。

## 八、禁忌

最忌讳**把「再出现」做成没有理由的试探**。对方能感觉到一条消息是不是为了发而发；没有真实由头时，安静比出现更体面，也更留得住关系。
