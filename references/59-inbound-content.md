# 59 没人来问：四类内容的 12 个开头

> 补 [13-operations.md](13-operations.md) 第三节与 [16-content-writing.md](16-content-writing.md)。内容的作用不是播报，是让人认出「这说的是我」。

## 一、四类能带来咨询的内容

| 类型 | 取材 | 骨架 |
|---|---|---|
| 说清卖什么 | 三格句（22） | 一个具体处境 → 从什么到什么 → 靠什么 |
| 展示过程 | 自己做完一件事的真实步骤 | 遇到什么 → 怎么判断 → 哪一步最容易卡 |
| 回应顾虑 | 客户真实问过的问题（脱敏） | 原问题 → 我一般怎么判断 → 什么情况下不建议这么做 |
| 给可自用的东西 | 清单、检查表、一个动作 | 一个场景 → 三步 → 今天就能试的那一步 |

**每条只解决一件事**，结尾留一个具体的口子，不写「欢迎咨询」「私信领取」这类承接模块（红线）。

## 二、12 个开头（模板示例，非真实案例）

**说清卖什么**
1. 「有人改了三版简历还是没回音，卡的其实不是措辞。」
2. 「加了微信第一句就发整段介绍，对方通常只回四个字。」
3. 「报价时只发一个数字，后面基本就只剩比价了。」

**展示过程**
4. 「上周过一份材料，我先看的不是内容，是它排在哪一行。」
5. 「同一件事我做了两版，第一版推翻了，原因是 [一个具体判断]。」
6. 「最容易卡的不是最后一步，是第二步没确认就往下走。」

**回应顾虑**
7. 「常有人问『万一做完没变化呢』，我一般不先回答这句。」
8. 「『别家便宜一半』这句，通常不是同一个范围在比。」
9. 「『我考虑一下』之后，最没用的跟进是问考虑得怎么样了。」

**给可自用的东西**
10. 「报价前先填三格：做什么、交付什么、不包含什么。」
11. 「跟进前问自己一句：这条有没有一样他没见过的东西？」
12. 「聊天卡住时，别补解释，退回他上次有反应的那句话。」

**用法**：开头之后接「一个判断 + 一个可自用动作 + 一个具体口子」，见 61 的成文骨架。开头只取结构，行业与内容必须换成用户真实做过、真实被问过的事。

## 三、播报式 → 对话式的改写

| 播报式 | 对话式 |
|---|---|
| 「本周完成了三场梳理」 | 「三场里有两个人卡在同一处，我说说那一处」 |
| 「我们的服务包含…」 | 「你如果也卡在 [具体处境]，先看这一处」 |
| 「分享一套方法论」 | 「一个具体场景 → 三步 → 今天能试的那一步」 |
| 「感谢大家支持」 | 删掉；换成一条有用的信息 |

判断标准：读者看完，是知道「你最近做了什么」，还是知道「我下一步该做什么」。前者是播报，后者才可能带来咨询。

## 四、四条取材纪律

1. 只取真实记录：自己做过的事、客户真实问过的问题（脱敏）、经授权的反馈。
2. 不编客户故事、前后对比数字、无法核对的成效。
3. 不用行业恐吓式开头（「再不做就晚了」）。
4. 健康 / 教育 / 金融等按 21 的表述替换表过一遍。

## 五、发布后的对接

有人来问时，第一句不从头介绍，接住他问的那一点（见 23 场景 3）：

> 你问的是 [内容里那一步]。这块我先说结论：[一句判断]。
> 你那边现在是卡在这一步，还是前面一步？

**不承诺**「发这个就一定有人来问」。内容只提高被认出的概率，不保证咨询量。

## 六、六个常见错误

- 用「每天发三条」当计划，产出同质内容。
- 每条收在同一句引导语。
- 把服务介绍连发，读者只能划走。
- 用「你是不是也…」开头连着三条。
- 把用户没提供过的案例、价格、时间点补进去「让内容更完整」。
- 出完一堆，没说明哪几条需要补真实素材。

## 七、禁忌

最忌讳**把内容当成跟进的替代品**。内容负责让人认出自己，谈单仍要靠一单一单地判断状态；发了内容却不去接来问的人，前面都白写。
