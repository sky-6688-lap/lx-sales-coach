# 52 交付期三个自然节点

> 补 [11-after-sale.md](11-after-sale.md) 第一节。复购是在交付期埋下的，不是到期才谈。

## 一、三个节点

| 节点 | 做什么 | 一句口径 |
|---|---|---|
| **阶段成果出来时** | 把「已经拿到的」和「还差一步的」分开说清，不夸大 | 「这版 [交付物] 你能用了；还差的是 [下一处]」 |
| **出现新情况时** | 指出来，并说明是否在本轮范围内 | 「这块是 [新情况]，不在这轮范围里；要不要我单独报一版」 |
| **收尾时** | 给一份「接下来可以自己做什么」的清单，再提可选的下一段 | 「接下来自己走先做 [动作一]，卡住的地方在 [动作二]，我写在清单里了」 |

第三个节点最反直觉：**先给不花钱也能继续走的路**，下一段合作才不是唯一选项，也就不用推销。

## 二、阶段成果那句话的写法

```
已经拿到的：[具体交付物，可核对]
还差一步的：[具体一处，不夸大]
什么时候补：[时间或条件]
```

**不要**：「效果非常明显」「进展特别顺利」这类无法核对的形容；也不写「你比刚开始好多了」这种替对方下结论的话。

**模板示例（非真实案例）**
> 这版 [文档] 你已经能直接用了。
> 还差的是 [具体一处]，等 [材料 / 时间] 到了我们过一遍。
> 中间卡住直接发我，不用攒着。

## 三、新情况与范围边界

交付期最容易发生的矛盾，是「这算不算包含在内」。处理顺序：

1. 先说清它是不是本轮范围里的（对照提案第 5 块）。
2. 不在范围内 → 平着说明，给单独报价的口子，不先做再谈钱。
3. 在范围内但会拖时间 → 说明影响，给一个选择。

> 这块是 [新情况]，不在我们这轮写的范围里。
> 我可以单独报一版，或者先按原范围把这轮收完，你选哪个？

**不要**默默做掉再期待对方主动加钱，也不要一句「这个不行」把话堵死。

## 四、收尾清单三段

```
1 你现在手上有什么：[交付物 1、2]
2 接下来自己走：先做 [动作一] → 再 [动作二]
3 容易卡住的地方：[一处]；卡住时可以 [一个自主动作]
```

清单是给对方自己用的，不带任何「想继续就得找我」的暗示。可选的下一段放在清单之后一句，且明确「不急」。

> 想有人一起过下一段，我们也可以按 [范围] 再走一轮，不着急定，你先用一阵看看。

## 五、六个不要

- 交付还没结束就推下一段。
- 把「客户挺满意」当成同意公开案例（见 56）。
- 用返佣或优惠提前锁下一轮。
- 把每个小进展都包装成成果汇报。
- 收尾时只讲价格优惠，不讲还剩什么问题。
- 交付期出问题还没处理完，就提转介绍（见 54 的时机）。

## 六、常见错误

- 只在到期前一周出现，平时零沟通。
- 阶段成果写成自我表扬。
- 「不包含」当时没写清，交付期靠临场解释。
- 把复购话术当成跟进消息，按 08 的节奏发。

## 七、禁忌

最忌讳**把交付期做成下一单的预热期**。对方付的是这一轮的钱，注意力应该在这一轮的结果上；把结果说清楚，下一段自然有得谈。
