# 98 温和语气：不激怒、不挑起不满的表达红线

> 这是 SKILL.md 运行时规则 17 与第七节红线 9 的落地篇。凡是要发给客户的消息，三版里的**每一版**都要过这一篇。所有对照均为**模板示例（非真实案例）**，须替换成用户提供的原词。

## 一、什么叫温和

温和不是软，不是讨好，更不是把「呀 / 呢 / 哦」堆进句子。温和是**让对方看完不觉得被纠正、被催促、被比较、被教育**，并且随时可以不回。

一句话判据：把消息读出声，想象客户正带着一点火气看到它——他会不会想「你这是在说我错了」「你又在催我」「你在拿我跟别人比」？三个里有一个是「会」，就重写。

温和的六个底线：

| 底线 | 具体含义 |
|---|---|
| 不否定 | 不否认对方的判断、预算感受、比价结论 |
| 不质问 | 不用反问去逼对方解释，不追问动机 |
| 不比较 | 不拿别家、别人、免费的东西压他 |
| 不施压 | 不设时限、不报名额、不暗示他犹豫是错的 |
| 不教育 | 不讲道理、不替他下结论、不评价他的情绪 |
| 留选择权 | 二选一、是或否、可暂不回，决定权在他 |

**温和 ≠ 三件事**：不等于道歉式铺垫（「不好意思又打扰」），不等于秒降价，不等于放弃边界。拒绝、不代写案例、不加链接，同样可以用温和的句式说清楚，见第八节。

## 二、六类禁用表达（出现即判不合格）

下面的左列一律不得出现在任何一版成品消息里。右列是替换方向，不是可以直接抄的模板。

### 1 否定与纠正

| ✗ 禁用 | ✓ 方向 |
|---|---|
| 你说得不对 / 其实不是这样 | 接住他那句里有道理的部分 |
| 你理解错了 / 可能你没看清 | 把信息补一条，不评价他看没看清 |
| 不是贵不贵的问题 | 直接回应他说的那个词 |
| 这不怪你，但是…… | 删掉转折，只说下一步 |
| 说白了 / 简单说就是 | 把结论写成一句事实 |
| 你应该 / 你必须 / 你得先 | 换成「可以先」「要不要」 |
| 我猜你是觉得…… | 不猜心思，只问他给的二选一 |
| 这个想法不太对 | 「这块我记下了」 |

### 2 质问与追问

| ✗ 禁用 | ✓ 方向 |
|---|---|
| 你是不是没看方案？ | 把那一页再发一次，不加问号 |
| 凭什么觉得贵？ | 「你说贵，我记下了」 |
| 为什么不买 / 哪里不满意 | 换成「用得上先看着，不用回我」 |
| 怎么一直没回？ | 补一条信息，不追究沉默 |
| 你到底要不要？ | 给是 / 否或二选一 |
| 是不是预算不够？ | 「是这次预算，还是想先看 [范围]？」 |
| 你考虑得怎么样了？ | 给一个具体小动作 |
| 你有什么不满意的跟我说 | 先接体验，再核对范围 |

### 3 比较与贬低

| ✗ 禁用 | ✓ 方向 |
|---|---|
| 免费的都不好用 | 「免费的确实不少」 |
| 别家没这个 / 别家做不到 | 只说自己这版的 `[范围]` |
| 别人都这个价 | 不提别人，只报自己这版规则 |
| 别人都买了 / 大家都在用 | 删掉整句 |
| 像你这样…… | 不给人归类 |
| 这个圈子都懂 | 不用圈内话压人 |
| 你这样会走弯路 | 「按你这情况，先做 [动作]」 |
| 比你去别处划算 | 不替他算账 |

### 4 施压与制造紧迫

| ✗ 禁用 | ✓ 方向 |
|---|---|
| 今天最后一天 | 删掉时限 |
| 不定就没了 / 名额紧张 | 删掉整句 |
| 下周就涨价 | 「什么时候定都不影响这版范围」 |
| 尽快回复 / 早点定 | 「不用急着回」 |
| 再不确认我就按原版做了 | 「这版先按 [范围] 留着」 |
| 已经有人下单了 | 删掉整句 |
| 机会错过就没了 | 只留事实与下一步 |
| 我等你到今晚 | 不设时间点 |

### 5 评价情绪与教育口吻

| ✗ 禁用 | ✓ 方向 |
|---|---|
| 别激动 / 你冷静点 | 「让你不舒服了，这句我先接住」 |
| 你急什么 | 不评价，只给事实 |
| 没必要这么大火气 | 先接体验 |
| 讲道理的话…… | 直接给可核对的信息 |
| 我跟你讲 / 听我说完 | 换成一句短事实 |
| 你这样想很正常（评价式） | 「我记下了」 |
| 其实你应该先…… | 换成二选一 |
| 我这是为你好 | 删掉整句 |

### 6 硬转折与甩锅

| ✗ 禁用 | ✓ 方向 |
|---|---|
| 但是 / 不过（放在句首顶回去） | 另起一条说事实，不转折 |
| 这不是我们的问题 | 先对范围，不先划责任 |
| 规则就是这样 | 把规则写成可核对的一页 |
| 我之前说过了 | 再发一次，不追责 |
| 可能是你那边…… | 只说自己这边的动作 |
| 我这边也很为难 | 不向客户倒情绪 |
| 那我也没办法 | 给一个还能做的小动作 |
| 反正…… | 删掉整句 |

## 三、三要：每版都要有

1. **先接住**：第一句复述或认可对方那句里有道理的部分，用他的原词，不空泛夸、不评价。接住不是拍马屁，是把「我听见了」放到最前面。
2. **留余地**：用「可以先」「要不要」「你看」「用得上再」这类可退可进的措辞，不把话说死。
3. **交回选择权**：结尾是是 / 否、二选一、一个具体小动作，或「不用急着回」；不写开放式盘问，不写连环追问。

**写法公式**：`[接住他那一句]` → `[一条可核对的事实或一个小动作]` → `[把选择权交回去]`。任何一版缺了第 3 步，读起来都会像在推他。

## 四、情绪升级自检五问

三版逐版默查，任一答「是」就重写那一版：

1. 这句里有没有在纠正他、说他理解错了？
2. 有没有问他「为什么」，或者要他解释自己的决定？
3. 有没有拿别人、别家、免费的东西跟他比？
4. 有没有时限、名额、催促，或暗示他再不定就是他的错？
5. 如果他正带着火气，看到这句会不会更不想回？

**另加一条整体检查**：三版里最「进」的 C 版，单独拿出来再过一遍这五问。C 版最容易写成催促，A、B 过关不代表 C 过关。

## 五、客户已经不满 / 发火时怎么降级

争议、退款、投诉、质疑不专业，这类场景按 [92-angry-client-recovery.md](92-angry-client-recovery.md) 与 [87-refund-and-dispute.md](87-refund-and-dispute.md) 处理，同时把三版整体往 A 档压：

- **三版都从接住起头**，不解释成本、不辩解、不先划责任、不追问「哪里不满意」。
- **C 版只给退一步的动作**：「我先不解释，等你方便时按那一处回你」「我先把范围页发你，你对完再说」，不给推进、不给时间要求。
- **不评价对方情绪**，不写「别激动」「理解一下」这类判词。
- **不在同一条里又道歉又提问又解释**，一件一件事拆开。
- 对已经明确拒绝的客户，三版里至少有一版是「可以先不回」的收法，给对方台阶。

## 六、不同场景的温和力度

| 场景 | 温和重点 | 最容易踩的雷 |
|---|---|---|
| 第一次接触、百元级 | 接住 + 一条信息，别上价值 | 一开口就讲「为什么值」 |
| 千元级、聊过两次 | 补可核对的范围与交付 | 拿案例和好评压过去 |
| 万元以上、长周期 | 留余地、不催、给可退的一步 | 设「本周确认」这类时间点 |
| 价格异议 | 不辩论、不秒降、不比较 | 「其实不贵」「一分钱一分货」 |
| 沉默跟进 | 补信息、不追究为什么没回 | 「是不是我哪儿没说清楚」 |
| 争议 / 退款 | 先接体验再对范围 | 先划责任、先解释 |
| 熟人 / 转介绍 | 不拿人情压对方 | 「都是朋友，你还信不过我」 |
| 多人决策 | 给能转发的材料，不催决策人 | 「你们内部尽快定一下」 |

## 七、20 组不合格 → 合格改写

左列是禁用或高风险表达，右列是方向示意；都要替换成用户原词才算成品。

1. ✗ 「其实不是贵，是没看到价值」 → ✓ 「你说贵，我记下了，先把 [范围] 说清」
2. ✗ 「你是不是没看我发的方案？」 → ✓ 「那页我再发你一次，用得上先看着」
3. ✗ 「为什么不买，哪里不满意？」 → ✓ 「这块先放着你这边，不用急着回」
4. ✗ 「免费的肯定不好用」 → ✓ 「免费的确实不少，够用就先用」
5. ✗ 「别家都没有我们全」 → ✓ 「我这边这次是 [范围] 和 [交付物]」
6. ✗ 「今天不定下周就调价」 → ✓ 「什么时候定都不影响这版范围」
7. ✗ 「你别激动，听我解释」 → ✓ 「让你不舒服了，这句我先接住」
8. ✗ 「说白了你就是没想清楚」 → ✓ 「是 [A] 还是 [B]，你看哪边更接近」
9. ✗ 「我猜你是预算不够」 → ✓ 「是这次预算，还是想先看清 [范围]？」
10. ✗ 「别人都这个价了」 → ✓ 「这版按 [范围] 报，规则写在 [规则页]」
11. ✗ 「你应该先试用再决定」 → ✓ 「要不要我先把 [清单] 发你？」
12. ✗ 「规则就是这样，没办法」 → ✓ 「我把规则页发你，我们对一下」
13. ✗ 「之前就跟你说过了」 → ✓ 「那一条我再发一次」
14. ✗ 「你这样会走弯路」 → ✓ 「按你这情况，先做 [动作]」
15. ✗ 「我这边也挺为难的」 → ✓ 「先按 [范围] 走，你看行不行」
16. ✗ 「你要是满意就尽快确认」 → ✓ 「这版先留着，你确认了再说」
17. ✗ 「不理解的话我再说一遍」 → ✓ 「我把 [那一项] 写成一页发你」
18. ✗ 「但是这次范围不能加」 → ✓ 「新增的 [需求] 不在 [范围] 里，我另列一版」
19. ✗ 「你先冷静下我们再说」 → ✓ 「我先不解释，等你方便时按那一处回你」
20. ✗ 「反正价格不能少」 → ✓ 「价格按 [范围] 定，范围变了价格才跟着变」

## 八、温和与红线的边界

温和只改**表达方式**，不改**判断与边界**。下面这些不因为「要温和」就松口：

- 不秒降价、不临时加赠没写进范围的东西；不因为怕客户不高兴就改报价规则。
- 不编案例、不报成交率、不写「经授权脱敏」「均可回溯」这类替用户假定素材的话。
- 不承诺结果、不写「保证」「一定」「包过」；不夸大、不教逼单、不制造稀缺。
- 不夹带课程链接、咨询入口、扫码与承接模块；对外只出现「乐享」。
- 行业合规表述（健康 / 教育 / 金融）照第七节红线，不因语气软就写疗效或收益承诺。
- **拒绝也要温和**：先一句边界，再给不含违规内容的等价动作，不写长篇免责声明，也不先答应再否定。

## 九、和 97 三版本的配合

- 三版都要过本篇；A 档最温和，B 档补信息时最容易写成纠正，C 档最容易写成催促。
- 争议场景三版整体降级（见第五节），不要出现「A 温和、C 却在推进」的断裂。
- 每版仍然 ≤3 条、单条 ≤60 字、方括号占位、一条只做一件事；温和不是把句子拉长的理由。
- 标注与适用条件写在引用块外，别让客户复制到「适用：客户有点情绪」这种内部话。

## 十、终检十条

- [ ] 三版里没有出现第二节的任何禁用表达？
- [ ] 每版第一句都接住了对方那句，没有先讲道理？
- [ ] 没有「为什么」「哪里不满意」这类要对方解释的问句？
- [ ] 没有拿别家、别人、免费的东西做比较？
- [ ] 没有时限、名额、涨价预告、催促或「尽快」？
- [ ] 没有评价客户情绪、没有教育口吻？
- [ ] 结尾把选择权交回去了（是 / 否、二选一、具体小动作、可暂不回）？
- [ ] 三版逐版过完情绪升级五问，C 版单独又过一遍？
- [ ] 温和没有换来秒降价、编案例、承诺结果或夹带链接？
- [ ] 客户已有不满时，三版都从 A 档起、C 版只给退一步动作？
