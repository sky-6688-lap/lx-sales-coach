# 36 价格异议三：别家便宜，怎么对齐口径

> 05 的第三分支。判断依据：对方报出别家价格、拿条款逐条对、或说「同样的东西别家 X」。

## 一、不评价同行，只对齐口径

价格差通常不是「同样的东西卖得贵」，而是**两版范围根本不是一回事**。动作是把可比项列出来，让对方自己判断；不贬低同行，不说「便宜没好货」，也不替用户猜别家包含什么。

**六个常见口径差**：

| 项 | 常见的差别 |
|---|---|
| 次数 / 时长 | 几次、每次多久、是不是同一人做 |
| 修改轮次 | 含几轮、超了怎么算 |
| 谁动手 | 对方给建议，还是直接交付成品 |
| 交付物形态 | 口头建议 / 文档 / 可编辑源文件 |
| 周期与响应 | 多久交付、卡住当天能不能问到 |
| 前置与后续 | 含不含诊断、交付后有没有一次复盘 |

## 二、标准接法（三段）

> 价格差我看到了，不评价别家。
> 我这边是 [次数 / 含几轮修改 / 谁来做 / 交付什么]，你可以拿这几项对一下。
> 如果对下来主要差在 [某一项]，我们也可以按你需要的范围重算一版。
> 要不要我把两版的差别列给你？

第三句给了「重算一版」的口子，但**重算必须对应范围变化**（见 27），不是把同样的东西降价。

## 三、12 组对照示例

以下均为**模板示例（非真实案例）**，只演示「把差别说清」的写法，不描述任何真实同行：

| # | 对方说 | 回应的落点 |
|---|---|---|
| 1 | 「别家便宜一半」 | 「可以留意一下次数和含不含修改，这两项差得比较多」 |
| 2 | 「同样的内容人家包三次」 | 「我这边是 [次数] 次，每次 [做什么]，你可以按次数对」 |
| 3 | 「人家送资料包」 | 「我这边交付的是 [具体东西]，形态不一样，看你要哪种」 |
| 4 | 「别家能一直改」 | 「我这边含 [数字] 轮修改，超出的部分单独算，先写清楚」 |
| 5 | 「别家是老师本人做」 | 「我这边谁做写在范围页第 3 块，你可以直接对」 |
| 6 | 「你们周期比人家长」 | 「周期差在 [具体环节]，要不要看一版更短的安排」 |
| 7 | 「别家先做后付」 | 「付款怎么安排按你定好的规则来，我这边不乱改」 |
| 8 | 「网上有免费的」 | 「免费的够用就先用；你要的是 [他提过的那件事] 有人一起过一遍」 |
| 9 | 「朋友能帮我弄」 | 「那挺好，先用他的；卡在 [他那一步] 再找我也行」 |
| 10 | 「我对比完再定」 | 「行，多看看是对的。对不上的地方发我，我按实际范围说」 |
| 11 | 「别家说能保证效果」 | 不评价、不跟承诺；只说「我不说包结果的话，能确定的是 [交付物]」 |
| 12 | 「你就说能不能按那个价」 | 「同样范围暂时没有下调空间；范围换成 [小一版] 我可以重报」 |

## 四、不跟的三种招

1. **不比保证**：对方拿「别人保证效果」来压，不跟着加码承诺（红线）。
2. **不比限时**：对方拿「别家今天有活动」来催，不制造自己的限时。
3. **不比贬低**：不说「那种便宜的做不了」，只说自己的范围与边界。

## 五、什么时候不必对齐

- 对方只随口提一句，没继续追问 → 接住即可，不主动展开对照表。
- 全程没说过自己的处境 → 属于比价型伪需求（见 29），回一句范围确认就够。
- 已经对齐过一次，对方仍在数字上打转 → 停，不再重复对照。

**别把对齐口径做成参数表轰炸**。列 3–4 项最相关的即可，用户的原话里提到哪一项就先对哪一项。

## 六、常见错误

- 立刻降价「那我也能做到这个价」。
- 说「他们那个不包含后续」，却没有依据。
- 把别家的名字、报价写进对外内容。
- 用「一分钱一分货」暗示对方贪便宜。
- 为了赢下比较，临时加赠没写进范围的东西。

## 七、禁忌

最忌讳**把比较变成辩论**。判断做对了的标志：对话从「谁便宜」转到「这次到底要包含什么」。三轮还停在价格数字上，说明该回到 34 的分类问句，而不是继续加对照项。
