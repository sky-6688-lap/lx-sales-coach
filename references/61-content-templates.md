# 61 内容成文模板、批量出稿与红线

> 补 [16-content-writing.md](16-content-writing.md)。出稿前先读这一篇，写完过 [15-message-checklist.md](15-message-checklist.md)。

## 一、先确认三件事（一轮问完）

1. **发在哪**：朋友圈 / 群 / 海报 / 短帖，决定长度与开头。
2. **给谁看**：用用户说过的具体处境，不要「所有想成长的人」。
3. **禁用表述**：行业合规词、不想提的价格、不能公开的案例。

没确认就按最保守口径：不写价格、不写案例、不写成效数字、不写承接语。用户说「别问了」按这个口径给，并标注假设。**不承诺爆款、不承诺咨询量。**

## 二、成文骨架

```
1 一个具体处境（用目标读者会认出的那句话开头）
2 一个判断（这件事通常卡在哪，为什么）
3 一个可自用的动作 / 三步清单（真给东西）
4 一个具体的口子（一句话能回，不是「欢迎咨询」）
```

长度：朋友圈 80–200 字为主；海报主文案 1 句主标题 + 1 句副标题；短帖可拆 3 条连发。

## 三、四个场景模板（模板示例，非真实案例）

**A 朋友圈 / 具体处境型**
> 有人改了三版简历还是没回音，其实卡的不是措辞，是没想清楚这一版要投给谁。
> 先别改格式，拿一张纸写出三个做过的项目里最想被问到的那一个，再看它排在哪。
> 排不到前两行的，先挪位置。
> 如果你也卡在「方向有了但写不出来」，把你那三行发我，我帮你看顺序。

**B 海报主文案**
> 主标题：报价前，先填三格
> 副标题：做什么 / 交付什么 / 不包含什么

**C 短帖三条连发**
> 1 「考虑一下」之后，最没用的跟进是问考虑得怎么样了。
> 2 有用的那个动作是：把大决定换成一个能一句话回的小确认。
> 3 比如问「[范围里这项] 是这次一定要的吗」。你上次那句是怎么接的？

**D 回应顾虑型**
> 常有人问「万一做完没变化呢」。我一般不先回这句。
> 先说清会拿到什么、过程做什么、需要你配合什么，以及哪块取决于你的投入。
> 不确定的地方不抹掉，反而更好判断。
> 你那边最想先确认的是哪一块？

**注意**：最后一句是具体口子，不是「私信我」「欢迎来聊」这类承接模块；后者属于红线，不写。

## 四、批量出稿规则

- **先定条数与差异维度**：5 条 = 2 条说清卖什么 + 1 条展示过程 + 1 条回应顾虑 + 1 条给动作。同骨架换词不算不同内容。
- **逐条标注取材来源**：写清基于用户提供的哪件事；没有来源的标为「需补真实素材」，不悄悄编。
- **不重复同一句原话**：不同客户的话不能混用。
- **不一次给 50 条同质内容**：先给 5–8 条，用户确认语气与边界后再扩。
- **交付格式**：编号 / 适用发布场景 / 正文 / 取材来源 / 需要用户补的一处（若有）。末尾一句「全部已过表述红线，未使用未经授权案例」，不写长段免责声明。

## 五、取材表（与 56 对接）

```
素材编号：
原话 / 事实（脱敏后）：
授权范围：[匿名 / 可截图 / 使用位置]
可用到什么时候：
不可用部分：
```

出稿时按授权范围取用；授权过期的、只许匿名却想放截图的，一律不用。

## 六、表述红线（内容场景最易踩）

- 健康：不写治疗 / 治愈 / 根治；教育：不写包过 / 保证提分 / 保 offer；金融：不写收益 / 稳赚。
- 不写「学员都已…」「好评如潮」「转化率提升 X%」等无法核对的表述。
- 不写限时、名额、涨价预告、倒计时。
- 不出现第三方人名、机构名、社群名，不夹带外部课程、专栏链接。
- 对外只出现「乐享」；不附加购买或咨询承接模块。

## 七、六个常见错误

- 把内容写成服务介绍连发。
- 用「你是不是也…」开头连着三条。
- 每条都收在同一句引导语。
- 补进用户没提供过的案例、价格、时间点。
- 出完一堆，没说明哪几条需要补真实素材。
- 把模板示例当成真实案例发布。

## 八、禁忌

最忌讳**为了凑条数牺牲差异**。用户要 50 条，先给 8 条有真实差异的并说明扩展方式；50 条同一句换词，看起来交了差，实际上一条都发不出去。
