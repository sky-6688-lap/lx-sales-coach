# 32 用客户原词：20 组改写对照与术语替换表

> 补 SKILL.md 第六节第 2 条与 [19-message-style-rewrites.md](19-message-style-rewrites.md)。核心：对方没说过的词，一个都别用。

## 一、为什么这条比「说得客气」重要

专业词会让对方不好意思纠正你。你说「你的核心诉求是交付确定性」，他明明想的是「怕做完不能用」，但为了不显得外行，会回一句「嗯，差不多」——误判就此固化，后面所有消息都建立在错的理解上。

用他的词，他才容易说「不是，我其实是…」。**纠正比顺畅更值钱。**

## 二、20 组改写对照

| # | 别这么写 | 改成（用他的原词） |
|---|---|---|
| 1 | 您的核心诉求 | 你刚说的 [他的原话] |
| 2 | 交付确定性 | 做完能拿到 [具体东西] |
| 3 | 赋能 / 助力 | 帮你把 [他的事] 做完 |
| 4 | 痛点 | 卡在 [他说的那一步] |
| 5 | 闭环 / 链路 | 从头到尾怎么走 |
| 6 | 认知升级 | 想明白 [他说的那个选择] |
| 7 | 全案 / 全套体系 | [次数] 次，给你 [文档 / 文件] |
| 8 | 深度陪伴 | 中间卡住当天能问到 |
| 9 | 定制化解决方案 | 按你说的 [他的情况] 来 |
| 10 | 转化 / 漏斗 | 从问到定这几步 |
| 11 | 用户心智 | 别人看到会怎么想 |
| 12 | 颗粒度 | 写得多细 |
| 13 | 对齐预期 | 先说清这次做哪块、不做哪块 |
| 14 | 价值锚点 | 为什么是这个价（范围变了什么） |
| 15 | 决策成本 | 你得花多少时间定这事 |
| 16 | 服务边界 | 哪些包含、哪些不包含 |
| 17 | 风险对冲 | 万一不合适，先做小一点的那版 |
| 18 | 复盘迭代 | 做完看哪一步卡了，下次改那一处 |
| 19 | 私域承接 | 加完之后怎么继续聊 |
| 20 | 情绪价值 | 先把他说的那件事接住 |

## 三、行业替换示例

| 用户卖的 | 客户常说的 | 别换成 |
|---|---|---|
| 求职陪跑 | 「投了没回音」「讲不出重点」 | 职业定位、竞争力模型 |
| 设计代做 | 「感觉不对」「再改改」 | 视觉调性、设计规范 |
| 养护服务 | 「总坚持不下来」「试过好多」 | 健康管理方案、调理体系（且不越合规边界） |
| 小课 / 陪学 | 「买了没动手」「没人盯就停」 | 学习闭环、督学机制 |
| B 端小服务 | 「说不清做到什么算好」 | 交付标准、验收体系 |

**替换方向永远是从抽象到具体**，不是从口语到专业。用户自己用专业词时，可以沿用；客户用口语时，不要替他升级。

## 四、三段改写练习

**原句 A**：「我们提供全方位定制化解决方案，帮助您实现能力提升。」
改写：先问「你说卡在哪一步」→ 用他的词重写。「你说改了三版还是没回音，这轮就处理这一句。」

**原句 B**：「本次服务包含三次深度咨询与全流程陪跑，确保交付确定性。」
改写：「三次，每次 60 分钟，中间给你一版能改的文档。做完你会拿到 [具体东西]。」

**原句 C**：「针对您的预算顾虑，我们可以提供灵活的付款方案。」
改写：「你说这次预算上不太方便——是这次不方便，还是想先确认做出来是什么样？」再加一句：「付款怎么安排，按你定好的规则来，我这边不乱改。」

## 五、四个检查点

1. 这段里有没有客户没说过的名词？
2. 有没有一个词，客户听到会不好意思说「不是」？
3. 引用他的话时，是不是逐字保留（可以截取，不能改写意思）？
4. 占位符 `[他的原话]` 是否真的替换了，而不是留在成品里？

## 六、常见错误

- 把客户原话「润色」得更礼貌，结果意思变了。
- 用「也就是说」把他的话翻译成自己的框架。
- 客户说「贵」，你写成「预算层面的顾虑」，避开了真正的词。
- 整个行业一套术语表，不看这一位客户怎么说话。

## 七、禁忌

最忌讳**把客户的话当成素材去包装**。原词的用途是让判断准确、让对方好纠正，不是让消息显得「更懂他」。带着包装目的引用，语气一眼就能看出来。
